# 文脉 · 山海卡

中国神话 3D 卡牌对战，新中式水墨风，浏览器即玩。

**▶ [在线试玩](https://xuqianjin-stars.github.io/wenmai-shanhai-card/)**（每次推送到 `main` 自动部署）

以卡为笔，以牌为墨。守护者随女娲之灵从昆仑墟出发，沿朝代往下走：先秦、秦汉、三国、唐宋、水浒、海丝、明清，直到晚清、民国和还没写完的今天。用灵将、符箓、文脉、器物和阵法驱散「遗忘」凝成的浊灵，把快被忘掉的名字找回来。

```bash
npm install
npm run dev        # http://127.0.0.1:5188
npm run build      # 产物在 dist/，任意静态服务器可托管（base 为相对路径）
npm test           # 规则引擎单元测试（86 项）
npm run soak       # 批量 AI 对局：先后手胜率、卡组对局、各关难度
npm run shot -- --q "battle=shenhua-1&auto=1" --out shots/a.png   # 无头截图（需本机 Chrome）
node tools/play.mjs --turns 5                                 # 用真实鼠标事件试玩若干回合
```

- **卡牌图鉴 · 升阶**：305 张玩家卡（212 灵将 / 6 符箓 / 32 文脉 / 21 阵法 / 34 器物）+ 59 张浊灵卡，共 364 张，29 组羁绊。凡品 → 珍品 → 极品（消耗文脉碎片，珍品解锁主动技能或强化效果），附出处与典故。灵将可按羁绊筛选。与真实文物有关的卡多一栏「文物」。
  器物里有上古十大神器（`divine: true`，卡面压「神」印），以及以真实文物为原型的条目（`relic`，压「物」印）。
- **文物志**：33 件真实文物，按章节解锁。只写能核实的硬事实：断代、出土地、现藏、尺寸，外加一句为什么值得记住。数据在 `src/data/relics.js`，按章节 slug（`CHAPTERS[i].key`）挂。照片来自 Wikimedia Commons，署名写在条目上。
- **守护者 · 修行**：碎片除了养卡也能养人，六条路永久强化主将——固本（气血上限 +10／级，8 级，点满 100）、磐石（受伤减免 +1，3 级，与其他减伤取最高）、养元（每回合开始回血 +1，5 级）、通灵（首回合灵力 +1，4 级）、博闻（起手多抽 1 张，3 级）、持盈（手牌上限 +1，3 级）。全部点满约 1900 碎片，是碎片的长线去处。数值表在 `src/data/guardian.js`，引擎只认算好的 `boon`；教学关不带加成，免得打乱写死的牌序。
- **牌组编成**：20 至 30 张、同名至多 2 张，费用曲线，自动补全。新解锁的灵将、符箓、文脉会试着编入；一次解开太多张，或起手牌组里没有的器物、阵法，只进图鉴。
- **设置**：总音量 / 音乐 / 音效、动画速度、回合计时（一炷香 30 秒）、教学提示、存档导出 / 导入、重置进度。进度保存在浏览器 localStorage，导出的是存档 JSON 本身，导入时照样走一遍 `migrateSave()`，旧版本存档在这里补迁移。

## 规则要点（docs/design/CORE_LOOP_v2.md v1.1）

- 主将 20 血；先手起手 4 张、后手 5 张；灵力 = 回合数（上限 10），先手首回合 2 点且不抽牌。
- 灵将留场、次回合起可攻击，每回合最多攻击 2 次（哪吒风火轮可攻击 2 次）；符箓即时生效后消散；文脉进入文脉区持续生效（上限 6）；阵法进入阵法区持续生效（上限 2，两座齐开时灵将攻击和防御 +1）。
- 伤害 = max(1, 攻 − 防)，五行相克 ×1.3；主将单次受伤至少 2 点，减伤效果取最高不叠加。
- 【守护】灵将在场时必须先击破它；控制最多连续 2 回合。
- 羁绊共 29 组。创世（盘古 + 女娲 + 创世图 / 五彩石）、八仙同渡、封神、诗文、西游、梁山等，成员到齐后给攻击、防御或抽牌。
- 五行共鸣：同属性符箓累计 2 张触发 2 回合，对方打出相克属性符箓可反制；另有五行结界、阴阳交汇、天地玄黄。
- 主将血量归零，或需要抽牌时牌库已空，判负。

## 操作

- 点击手牌选中，再点一次或拖到场上即可打出；需要目标的牌会拉出一支朱砂箭头，点目标即可。
- 点己方可行动的灵将（绿光）后点目标攻击；已升阶的灵将会出现「施展技能」按钮。
- Enter / E 结束回合，Esc 或右键取消选择；鼠标悬停任意卡牌、主将可看详情。
- 触摸屏没有悬停，点选卡牌时同时弹出详情面板。

## 浏览器与设备

桌面浏览器任意窗口比例都能玩：相机按视口宽高比自动退推取景，手牌扇形也按可用宽度收拢（`src/render/camfit.js`），16:9 及更宽时与原构图完全一致。

iPad 与 iPhone **请横屏**——牌桌是横向构图，竖屏时卡面会小到读不了字，因此竖屏直接提示旋转设备。已处理刘海与 Home 条安全区、双击缩放、下拉刷新与长按菜单；悬停态只在真正有指针的设备上生效。视口尺寸一律取自 `visualViewport` 实测值（`src/render/app.js` 写成 `--vw` / `--vh`），微信等内置浏览器把原生工具栏叠在布局视口上时也不会错位。

**全屏**：桌面、Android 与 iPadOS 走 Fullscreen API，设置里有开关，触屏设备在标题页「开卷」那一下会顺手请求全屏。iPhone 的 Safari 至今没有网页全屏 API，那里唯一的真全屏是**添加到主屏幕**后从图标启动（`apple-mobile-web-app-capable` + `public/manifest.webmanifest`），主菜单的「帮助 · 屏幕」一页会给出具体步骤。图标由 `node tools/icon.mjs` 生成。

## 技术

- **three.js + Vite**。音频仍全部由 WebAudio 实时合成；画面以程序化水墨为主，部分人物、文物和时代地图用了可核验的图片（`public/card-art/`）：
  - 卡面、立绘、场景背景以 Canvas 2D 程序化水墨绘制（笔触、飞白、晕染、泼墨、回纹、印章），见 `src/render/ink.js` 与 `cardArt.js`；
  - 大部分卡牌有**专属出场 / 技能特效**（花瓣、绸带、笔锋、星轨、护罩、碎片、光束、落雨等），按卡牌 id 配在 `src/game/cardvfx.js`，与规则完全解耦；
  - 场景后期处理：一次全屏着色器完成深度 Sobel 墨线、降饱和、暖色纸调、宣纸纹理、暗角和 ACES 色调映射（`src/render/app.js`）；
  - 音频全部由 WebAudio 实时合成：古琴（Karplus-Strong 算法）、箫、堂鼓、锣、编钟，按场景生成五声音阶配乐（`src/audio/`）。
- **规则引擎**（`src/rules/engine.js`）是纯数据：状态可以直接 `structuredClone`，`act(state, action)` 返回事件列表。AI、测试和画面共用同一套规则；表现层（`src/game/battle.js`）只负责把事件播放成动画。
- **AI**（`src/rules/ai.js`）：对每个合法动作克隆局面、执行后用估值函数评分，只看一步；难度通过评分噪声和「宗师」档额外看一步对手回合的保守估计来区分。

目录：`src/data`（卡表、剧情）· `src/rules`（规则、AI、测试）· `src/render`（渲染、卡牌网格、场景、特效）· `src/audio` · `src/game`（启动、界面、战斗、存档）· `tools`（截图、试玩脚本）。

调试用 URL 参数：`?battle=shenhua-3`（直接进入关卡，也可用 `p-stage` 这类自由对战 id）、`&auto=1`（AI 代打）、`&speed=2`、`&screen=menu|collection|deck|story|practice|quiz`、`&unlock=1`（全卡 + 999 碎片）、`&reset=1`（清空存档），以及 `?scene=gallery`（平铺全部卡面）。
