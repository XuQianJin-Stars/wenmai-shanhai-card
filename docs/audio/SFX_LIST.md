## 音效命名规范

```
sfx_[类别]_[事件]_[变体序号（可选）]
amb_[场景]_[描述]

示例：
  sfx_ui_btn_click
  sfx_card_summon_general_01
  sfx_skill_lunhui_cast
```

## 十、五行克制专项音效层（v3 新增，P1 优先级）

> 对应 CORE_LOOP_v2.md §3 五行克制矩阵（×1.3 攻/×0.7 防）。  
> **评估结论**：五行克制命中是本游戏最高频率的「策略成功反馈」时刻，值得独立音效层而非复用通用命中音。音效设计须满足三个约束：  
> ① **文化准确性**：每种五行用历史上对应的中国传统乐器/声音象征；  
> ② **可辨识度**：玩家无需看 UI 提示，仅凭音效即可识别触发了哪种五行克制；  
> ③ **不打断叙事节奏**：总时长 ≤ 0.8s，且音效结束后 BGM stem 正常衔接。

---

### 10.1 五行克制音效设计原则评估

#### 是否需要为五行克制单独建一层？

**结论：需要。理由如下：**

| 评估维度 | 现有 `sfx_attack_crit`（通用） | 五行克制专用层 |
|---------|-------------------------------|--------------|
| 文化信息量 | 零（通用爆发声） | 高（玩家知道「是火克了金」） |
| 策略反馈 | 弱（与普通命中混淆） | 强（识别克制 → 强化记忆 → 提升博弈意识） |
| 新手引导价值 | 无 | 直接替代教程：「哦，这个颜色打那个颜色效果好」 |
| 制作成本 | 已完成 | 5 组 × 2 音效 = 10 条（可由通用crit音效叠加五行修饰层实现） |
| 引擎实现 | 直接播 | MetaSound Patch 参数化（1个MSPatch + 5组参数） |

**技术实现策略（最优性价比方案）**：  
不制作 10 条独立音频，而是 **1 条通用克制底层 + 5 个五行修饰音频层**，在 MetaSound Patch 中动态混合。  
工程侧仅需 1 个 GameplayTag (`Audio.SFX.Combat.WuxingCrit`) + 1 个枚举参数 (`WuxingElement: Gold/Wood/Water/Fire/Earth`)。

**critic 预审通过后的分阶段制作策略（v3.1 新增）**：

| 阶段 | 里程碑 | 制作内容 | 条数 |
|------|--------|---------|------|
| 阶段一 | M1–M2 | P0 全部（UI+召唤+战斗基础）+ 五行克制层（15条素材） | ~67 条 |
| 阶段二 | M3 | P1 技能音效精简版：每卡 cast/impact 合并为 1 条，去掉珍品技能音效，共约 36 条（削减自 57 条） | ~36 条 |
| 阶段三 | M4+ | P2 环境音（9条）+ 珍品技能音效（约 21 条）+ 追加内容 | ~30 条 |

> 珍品技能音效推迟至 v1.1 制作，MVP 核心音效 P0+P1 精简版约 103 条，配合 AI 生成工具可行。

### 10.5 五行克制感知强化——「浮字+音效」双通道对照

> 对应 CORE_LOOP_v2.md §9.4「五行克制的延迟感知设计」。  
> 音效层与视觉层协同触发时序：

```
攻击命中判定帧 (T=0)
  ├── [视觉] 伤害数字浮字出现（颜色加亮）     T+0ms
  ├── [视觉] 「五行克制！」浮字 + 对应颜色闪光 T+50ms
  ├── [音效] sfx_crit_[element] 主音效播放     T+0ms  ← 与命中同步
  └── [音效] sfx_crit_residual_[element] 叠加  T+300ms ← 在主音效中段叠入

总体感知：「听到了独特的声音 + 看到了浮字」→ 双通道印证 → 记忆锚定
```

> **⚠️ M2 集成测试时序风险（critic 预审标注）**：  
> 需与 engineer 在 M2 确认：CORE_LOOP §8「战斗结算子流程」中，HP 扣减（步骤④）与命中事件是否同帧触发。  
> 若「五行克制！」浮字动画与 HP 变化共用同一帧事件，T+50ms 的浮字可能在 HP 扣减显示之前出现，造成视觉错位。  
> 不阻塞当前制作，但 M2 联调时需验证：**事件触发顺序应为「HP 扣减先 → 浮字后」**，如有错位则由 engineer 调整帧事件顺序。

### 10.6 MetaSound 实现规格（给 engineer 的接口要求）

```
BP_WuxiaAudioManager 调用方式：
  Event Tag:  Audio.SFX.Combat.WuxingCrit
  Parameters:
    AttackerElement  (EWuxingElement enum: Gold/Wood/Water/Fire/Earth)
    DefenderElement  (EWuxingElement enum: 用于选择残响层)
    ImpactIntensity  (float 0.0–1.0，基于实际伤害量，影响主音效音量+1.5dB)

MetaSound Patch 结构：
  MS_WuxingCrit
  ├── Input: AttackerElement → 路由到对应五行音色层（5路 Switch）
  ├── Input: ImpactIntensity → 调制整体音量（Output Volume = 0.8 + 0.2*ImpactIntensity）
  └── Output: 主音效 + 残响层（自动从 AttackerElement/DefenderElement 参数选取）

Sound Class: SC_SFX_Card（已在 ARCHITECTURE.md 3.10 定义）
优先级: Priority 90（高于普通命中音 70，低于羁绊激活 110）
```

### 10.7 五行克制音效评估小结

| 评估项 | 结论 |
|--------|------|
| **是否需要独立音效层** | ✅ 需要，新手感知价值高，制作成本可控 |
| **最优实现方案** | 1 MSPatch + 5 组乐器音色层 + 5 组残响层 = 15 条素材（非 10 条独立音效） |
| **制作优先级** | P1，M2 一并制作（critic 预审通过 ✅ 2026-04-30） |
| **克制×1.3的音效强度** | 主音效音量基准 = sfx_attack_heavy +3dB，短促有力但不震耳 |
| **与 BGM 的冲突风险** | 低。最长 0.7s，Sound Mix SM_Combat_Duck 期间 BGM 已降 -4dB，安全窗口充足 |
| **与五行结界激活的混淆风险** | 无。五行结界激活（sfx_resonance_activate，2.5s 宏大感）远长于克制音效（≤0.7s），玩家不会混淆 |
| **水克火瓷碗方案** | 制作时同时生成「瓷碗叩击版」和「陶钵版」供 critic 盲听决选 |
| **火克金堂鼓方案** | 如 critic 盲听认为火感不足，备选为「竹节爆裂+炉火噼啪」 |
| **M2 时序风险** | HP扣减与克制浮字帧顺序需 M2 联调验证，不阻塞制作 |
