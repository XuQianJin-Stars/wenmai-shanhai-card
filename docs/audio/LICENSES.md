## 五、版权合规 Checklist（发布前必查）

### BGM 生产前
- [ ] Suno 账号已确认为 Pro（$10/月）或 Premier（$30/月）计划
- [ ] Udio 账号已确认为 Standard（$8/月）或 Pro（$30/月）计划
- [ ] 第三节 BGM 生成记录表中"账号/计划"列已填写

### BGM 生产中（每首必执行）
- [ ] 每次生成后通过 Suno "Claim Ownership" 标记版权归属（仅 Suno）
- [ ] 每次生成后记录 Prompt Hash 到第三节记录表
- [ ] 生成后 6 个候选版本已存入 `references/audio/bgm_candidates/`
- [ ] **每首候选版本生成后立即通过 ACRCloud 相似度检测**（ACRCloud Hum 或 API）
  - 相似度 < 80%：通过，记录检测结果到第三节记录表"备注"列
  - 相似度 ≥ 80%：**必须重新生成**，禁止使用该版本，无论其他维度多优秀
  - 检测频率：**每一首，每一个候选版本**（非仅最终选定版）
  - Udio 生成内容尤其需要此步骤（critic AU-MED-001 强调，2026-04-30）

### BGM 生产后（发布前）
- [ ] 所有最终 BGM 已在生产中完成 ACRCloud 检测并记录（≥ 生产中检测的重复核验）
- [ ] 关注 Suno/Udio vs RIAA 诉讼最新进展；若商用授权被限制须启动替换预案
- [ ] 若商业发行定价 > 免费（含 DLC/付费下载），重新审查 AI 生成内容的版权归属声明

### 素材合规
- [ ] 所有来自 Freesound.org 的素材确认为 CC0 授权（非 CC-BY、非 CC-BY-NC）
- [ ] 所有来自 Spitfire LABS 的采样已完成 EULA 账号注册
- [ ] 第三节 Freesound CC0 素材表无空行（每条素材 ID 和用途均已填写）
- [ ] 无使用任何需要版税（Royalty）的商业音效库素材
- [ ] 无使用任何真实戏曲/传统音乐录音（即使标注为"民间传统"亦须核实）
- [ ] 无使用任何其他商业游戏/作品的音频（禁止抄袭）

## 六、版权风险提示

1. **AI 生成内容的训练数据问题**：目前 Suno/Udio 的训练数据版权争议尚在法律层面讨论中（多起诉讼案件进行中）。建议在商业发布前关注最新法律动态，并在条件允许时将关键 BGM 替换为人工创作版本。

2. **声音相似性检测**：AI 生成内容可能无意中与受版权保护的音乐高度相似。建议对最终使用的 BGM 进行声音识别检测（如 AudD、ACRCloud）。

3. **戏曲采样风险**：绝不使用真实戏曲唱腔录音（昆曲、京剧等），其中可能包含特定表演者的权利。
