## 一、核心美学定位

**新中式·意境声学**

以"意境先于旋律、留白胜于堆砌"为首要原则。声音的首要任务是唤起中国传统美学中的"气韵"，而非填满听觉空间。

**坚决避免**：
- 大量打击乐齐鸣的"庙会感"/"春晚感"
- 过度花哨的电子合成器铺底（流行中国风陷阱）
- 西洋弦乐大编制衬托中国乐器（显得"贴皮"）
- 重复单调的东方五声音阶 loop（"塑料感"来源之一）

**核心意象**：竹林听雨、高山流水、古寺钟声、夜读灯火

## 二、乐器编制体系

### 2.1 主奏乐器（骨架）

| 乐器 | 音色特点 | 主要用途 | 优先级 |
|------|----------|---------|--------|
| 古琴 | 低沉、沉郁、余韵绵长 | 书斋场景 BGM、静谧段落 | P0 |
| 竹笛 | 清脆、明亮、穿透力强 | 昆仑墟空灵主旋律 | P0 |
| 箫 | 幽深、内敛、泛音丰富 | 过渡段落、哀婉段落 | P0 |
| 编钟 | 金属感、庄严、宽泛回声 | Boss 战起始、仪式感片段 | P1 |
| 磬 | 清越、点缀性、共鸣长 | 回合切换提示音、文脉激活 | P1 |
| 箜篌 | 细腻、流动、如水般的琶音 | 胜利曲、文脉羁绊触发 | P1 |
| 琵琶 | 激烈、弹拨感、可模拟紧张感 | 战斗 BGM 副旋律层 | P1 |
| 二胡 | 情感表达强、苍凉感 | 失败曲、情绪转折点 | P2 |

### 2.2 节奏层（结构支撑）

| 乐器 | 用途 | 限制 |
|------|------|------|
| 堂鼓（单击/段落鼓点） | 战斗场景张力、Boss 出场 | 避免连续密集滚奏（庙会感） |
| 板（拍板） | 古戏台场景节拍骨干 | 仅限古戏台场景使用 |
| 铜锣（单击） | 特殊事件强调（符箓共鸣激活） | 稀疏使用，每曲最多 2-3 次 |
| 木鱼 | 书斋场景轻微律动 | 极轻音量，作为底层纹理 |

### 2.3 电子氛围层（辅助，不抢主奏）

| 类型 | 描述 | 用途 |
|------|------|------|
| 生成式田野录音（Field Recording 处理） | 风声、水声的电子化延伸 | 昆仑墟场景底层氛围 |
| 细粒度采样拉伸（Granular Synthesis） | 古琴/磬的共鸣延伸 | Pad 层，制造空间感 |
| 低频无调性 Drone | 极低音量的持续音 | Boss 战紧张底层 |
| 反转采样（Reversed Hits） | 来自编钟或磬的逆向音效 | 技能释放前的铺垫音效 |

**电子层音量规则**：电子层整体音量不超过主奏乐器的 -12dB，确保"辅助"定位。

## 三、调式与音阶规范

### 3.1 五声音阶框架

以**宫调式**（do-re-mi-sol-la，接近 C 大调五声）为基础调性中心。

| 调式 | 主音 | 情感特征 | 适用场景 |
|------|------|---------|---------|
| **宫调式** | do（1）| 庄严、稳定、中正 | 主菜单、书斋 |
| **商调式** | re（2）| 苍凉、悲壮、辽阔 | 失败、哀伤过渡 |
| **角调式** | mi（3）| 清新、生机、积极 | 胜利、羁绊激活 |
| **徵调式** | sol（5）| 热烈、欢快、明朗 | 古戏台战斗 |
| **羽调式** | la（6）| 清冷、空灵、深远 | 昆仑墟、Boss 战高潮前 |

### 3.2 调式切换规则

- **同场景内**：不切换主调式，通过副旋律在五声内游走
- **场景间切换**：用 2-3 音的共同音作为桥接，避免跳调断层
- **战斗紧张度上升**：可临时引入偏音（4、7），但需快速解决回五声框架
- **Boss 战**：允许使用更大的调性张力（调内半音），但主题旋律保持五声骨干

## 四、BPM 区间规范

| 场景/情境 | BPM 范围 | 拍号 | 备注 |
|----------|---------|------|------|
| 主菜单 | 52–68 BPM | 4/4 | 自由节拍感，接近散板 |
| 书斋（剧情） | 40–56 BPM | 4/4 or 3/4 | 空灵感优先，可有渐速 |
| 昆仑墟（战斗） | 88–108 BPM | 4/4 | 中速，保持清冷意境 |
| 古戏台（战斗） | 120–144 BPM | 4/4 | 热烈明快，戏曲节奏感 |
| Boss 战 | 104–120 BPM | 4/4 | 紧迫但不急促 |
| 胜利 | 96–112 BPM | 4/4 | 欢快但不流俗 |
| 失败 | 48–64 BPM | 3/4 | 缓慢、低沉、余韵 |

## 五、场景音画对应规范

### 5.1 昆仑墟 — 清冷空灵

```
视觉参照：悬浮山石 + 祥云 + 古松 + 冷蓝光影（Lumen 冷白光）
音画目标：听觉上感受"高山之巅的寂静"，如站在云端俯视万物
```

| 音频层 | 描述 | 具体实现 |
|--------|------|---------|
| 底层（Ambient） | 极低音量的高山风场录音 + 轻微颗粒化处理 | 循环 amb_kunlun_wind.ogg |
| 中层（Texture） | 箫的长音 + Granular 拉伸延伸 | 每 8-12 秒触发随机短音 |
| 主层（Melody） | 竹笛清脆主旋律，羽调式，BPM 88-108 | BGM 主旋律层 |
| 点缀（Accent） | 磬的单击，共鸣 3-4 秒 | 回合开始、卡牌召唤时触发 |

**严格禁止**：堂鼓、琵琶、任何二胡元素。

### 5.2 古戏台 — 热闹民乐

```
视觉参照：红灯笼 + 雕花栏杆 + 舞台 + 暖黄灯光
音画目标：充满生命力的戏台氛围，民间庆典感，但有节制（不是婚丧嫁娶）
```

| 音频层 | 描述 | 具体实现 |
|--------|------|---------|
| 底层（Rhythm） | 板的稳定律动 + 轻堂鼓段落鼓点 | 构成节奏骨架 |
| 中层（Harmony） | 琵琶快速弹挑 + 横笛 | 活跃的对位感 |
| 主层（Melody） | 横笛/唢呐风格竹笛明快主旋律，徵调式 | BGM 主旋律层 |
| 点缀（Drama） | 锣鼓"经"（板+鼓组合短句） | 卡牌出牌、战斗命中时偶发 |

**关键原则**：需保留中国戏曲的"腔调"感（旋律中有装饰音、滑音），但绝不能使用真实戏曲唱腔采样（版权风险）。

### 5.3 书斋 — 静谧古琴

```
视觉参照：笔墨纸砚 + 古籍书架 + 烛光 + 深色木质
音画目标："万籁俱寂，唯闻翻书声"的学者之境
```

| 音频层 | 描述 | 具体实现 |
|--------|------|---------|
| 底层（Ambient） | 极轻的蜡烛火焰声（电子处理后无噪感） | 音量 -24dB 以下 |
| 中层（Texture） | 木鱼极轻律动 + 古琴弦鸣共鸣 | 填充寂静感 |
| 主层（Melody） | 古琴单弦旋律，宫调式，散板感，BPM 40-56 | 稀疏、每 4-8 秒一句 |
| 叙事层（Narrative） | 翻书页声音（SFX 层，不在 BGM 内） | amb_shuzhai_page.ogg |

**关键原则**：旋律密度极低，大量留白（silence as music）。古琴演奏需有散板感，不能机械对齐节拍格。

## 六、动态混音策略（战斗紧张度切层）

### 6.1 分层结构（Layered Stems）

每首战斗 BGM 分为以下可独立控制的音轨层：

```
战斗 BGM 分层架构：
├── Layer 0: Ambient（环境底层）          — 始终播放
├── Layer 1: Melody_Base（基础旋律）      — 始终播放
├── Layer 2: Rhythm（节奏层）             — 战斗开始激活
├── Layer 3: Harmony（和声填充层）        — 紧张度 > 50% 激活
├── Layer 4: Intensity（强度层/高密度）   — 紧张度 > 80% 激活
└── Layer 5: Drama（戏剧性高潮层）        — Boss 出场/技能释放时短暂叠加
```

### 6.2 紧张度计算（供 Engineer 参考）

```
紧张度 Intensity (0.0 ~ 1.0) 由以下因素决定：
+ 玩家 HP 低于 30%            → +0.3
+ 对手场上卡牌数量 ≥ 3 张     → +0.2
+ 符箓结界激活中               → +0.1
+ 连续 2 回合未攻击成功         → +0.1
+ Boss 战场景                  → +0.5（强制叠加）
- 玩家灵将数量优势明显          → -0.1
```

### 6.3 层切换规则

| 紧张度阈值 | 激活层 | 过渡时长 | 触发方式 |
|-----------|--------|---------|---------|
| 0% → 进入战斗 | Layer 0 + 1 | 即时 | OnCombatStart |
| ≥ 20% | + Layer 2（节奏层） | 2s 淡入 | 紧张度变更事件 |
| ≥ 50% | + Layer 3（和声层） | 1.5s 淡入 | 紧张度变更事件 |
| ≥ 80% | + Layer 4（强度层） | 1s 淡入 | 紧张度变更事件 |
| Boss 出场 | + Layer 5（短暂 4s） | 0.5s 淡入 | OnBossEnter |
| 战斗结束/胜利 | 全层淡出 → 切胜利 BGM | 3s 淡出 | OnCombatEnd |
| 战斗结束/失败 | 全层淡出 → 切失败 BGM | 2s 淡出 | OnCombatEnd |

### 6.4 Loop 点规范

- 所有 BGM 必须设置 **精确 Loop 点**，精度 ≤ 10ms
- Loop 点需落在小节线上（4/4拍）
- 推荐使用 UE5 MetaSound 的 `SoundWave Loop` 功能管理
- 层切换同步到 **最近的小节线**，避免节拍错位

## 七、音频技术规范

### 7.1 文件格式规范

| 类型 | 格式 | 质量参数 | 最大文件大小 |
|------|------|---------|------------|
| BGM | .ogg | Vorbis q5（约 160kbps） | 3MB / 首 |
| 环境音（循环） | .ogg | Vorbis q4（约 128kbps） | 1.5MB |
| 卡牌/技能 SFX | .wav | 16bit 44.1kHz 单声道 | 200KB |
| UI SFX | .wav | 16bit 44.1kHz 单声道 | 100KB |
| 环境点缀 SFX | .ogg | Vorbis q3 | 200KB |

### 7.2 响度规范（LUFS）

| 类型 | 目标响度 | 峰值上限 |
|------|---------|---------|
| BGM（主菜单/剧情） | -18 LUFS | -3 dBTP |
| BGM（战斗） | -14 LUFS | -1 dBTP |
| SFX（技能/攻击） | -12 LUFS（瞬态峰值） | -1 dBTP |
| UI SFX | -16 LUFS | -3 dBTP |
| 环境音 | -24 LUFS | -6 dBTP |

> 所有交付文件须经 Loudness Normalization 处理后提交。

### 7.3 采样率要求

- 统一使用 **44100 Hz**
- BGM 立体声（Stereo），SFX 单声道优先（减小文件体积）
- 3D 空间化音效使用单声道（UE5 Attenuation 系统接管空间化）

## 八、音频风格参考方向

> 注意：以下为参考风格方向，不是直接采样来源。仅供创作参考。

- **古琴意境**：参考古琴名曲《广陵散》《流水》的留白手法，而非流行改编版本
- **空灵氛围**：参考日本游戏《大神》的和风音效处理方式（将传统乐器与自然音结合）
- **戏台活力**：参考昆曲、南音的器乐演奏段落，提取节奏感而非唱腔
- **电子氛围**：参考 The Caretaker 的 granular 质感处理，用于底层 pad 层

## 九、盲听评审标准（AU-MED-002，与 critic 共同建立）

> 本标准用于 critic 对 BGM 小样进行一致性盲听评审。每首 BGM 候选须达到合格线方可进入实现阶段。

### 9.1 评审流程

1. **盲听**：critic 不看场景标签，直接听，30 秒内写下第一感受
2. **打分**：对照以下四个维度逐项打分
3. **结论**：总分达到合格线 → 通过；否则返回 audio 修改并重新提交

### 9.2 评审维度与评分标准

| 维度 | 分值 | 合格要求 | 说明 |
|------|------|---------|------|
| **风格符合度** | 1–5 分 | ≥ 4 分 | 能感知水墨/传统中国美学；无西方流行感；无「塑料感」（合成器假感）；无「春晚感」 |
| **情绪匹配度** | 1–5 分 | ≥ 3 分 | 战斗 BGM 给人紧张感；探索/书斋 BGM 有悠远意境；与对应场景视觉语言（冷/暖/深）一致 |
| **循环缝合点** | Pass/Fail | Pass | BGM 循环接缝无明显突兀感；在 4 小节内能完成自然衔接；接缝处无明显音量跳变或音调断层 |
| **混音响度** | Pass/Fail | Pass | 战斗 BGM：-14 LUFS ±2；菜单/书斋 BGM：-18 LUFS ±2；峰值不超过 -1 dBTP |

**合格线**：风格符合度 ≥ 4 分 + 情绪匹配度 ≥ 3 分 + 循环 Pass + 响度 Pass

> 风格符合度不足 4 分时，无论其他维度得分如何，一律视为不合格（风格是本项目核心红线）。

### 9.4 场景 BGM 反差设计原则（AU-LOW-001）

书斋场景与战斗场景 BGM 需形成鲜明声音反差，防止情绪混淆：

| 场景 | 主驱动乐器 | 节奏感 | BPM | 动态范围 |
|------|-----------|--------|-----|----------|
| **书斋（BGM #4）** | 古琴独奏 + 木鱼极轻 | 散板/无节拍感 | 76 BPM | 极窄，长时间 pp 级 |
| **昆仑墟战斗（BGM #2）** | 竹笛主旋律 + 磬节拍 | 有节拍，但空旷 | 96 BPM | 中等，随紧张度扩展 |
| **古戏台战斗（BGM #3）** | 琵琶 + 横笛 | 强节拍，戏曲感 | 132 BPM | 宽，热闹 |
| **Boss 战（BGM #5）** | 编钟开场 + 琵琶 + 堂鼓 | 强节拍，威压感 | 112 BPM | 最宽，全层推进 |

**关键原则**：
- 书斋 BGM 的「主角」永远是古琴的沉默与留白；战斗 BGM 的「主角」是节奏推进感
- 评审时如书斋 BGM 被 critic 感知为「有一点战斗感」，即视为情绪匹配度扣分项
- 昆仑墟战斗：「冷峻、空旷」而非「热血」——竹笛 + 磬确保与古戏台的热烈形成区分
