# 《文脉·山海卡》开发路线图 ROADMAP

> 版本：v1.2 | 更新：2026-04-30 | 负责人：producer

---

## 总体目标

**6~12个月内**完成 MVP 可玩版本，遵循"轻量化、特色化、可落地"原则。

---

## 砍需触发机制（应对 R-PM01 风险）

> 单人开发精力有限，每个里程碑设定"完整版"与"最小可交付版本（MVV）"，当触发条件满足时自动降级至 MVV，保证项目持续推进而非卡死。

| 触发条件 | 触发后行动 |
|---------|-----------|
| 任一 Sprint 超期 ≥ 1 周 | producer 评估是否启用该阶段 MVV，延迟任务进入迭代池 |
| 连续 10 天无有效提交 | 立即切换至 MVV，砍去当前 Sprint 中非核心任务 |
| 累计进度落后 ≥ 25% | 召开全项目审视，重新评估哪些功能移出 MVP 范围 |

### 各阶段最小可交付版本（MVV）

| 阶段 | 完整版目标 | MVV（精简底线） | 可延迟内容 |
|------|-----------|----------------|-----------|
| M0 | 3个场景占位 + 20张卡牌低模 + 完整框架 | 1个场景占位 + 3张卡牌可拖动 + 数据表骨架 | 其余场景、其余卡牌建模 |
| M1 | 20张卡牌 + 文脉羁绊 + 符箓共鸣 + AI | 10张卡牌 + 基础胜负逻辑 + 随机AI | 羁绊系统、符箓共鸣、AI策略 |
| M2 | 12章故事 + 13场景精化 + 完整UI + 养成 | 1章故事 + 1场景精化 + 基础UI | 其余章节、其余场景精化 |
| M3 | 60fps + 全面平衡测试 + 完整操作优化 | 45fps 可玩 + 核心 bug 修复 | 极致性能优化、移动端 |

## 阶段概览

| 阶段 | 时长 | 核心目标 | 里程碑标志 |
|------|------|----------|-----------|
| M0 · 准备与基础搭建 | 1~2个月 | 框架就绪、资源到位 | 能在 UE5 中启动一张可拖动的3D卡牌 |
| M1 · 核心玩法开发 | 2~3个月 | 可玩回合制对战 | 完整一局 PvE 对战跑通 |
| M2 · 美术与剧情完善 | 2~3个月 | 视觉品质与内容填充 | 3个场景+故事模式通关 |
| M3 · 测试与优化 | 1~2个月 | 稳定可发布 | 60fps、无崩溃、平衡性通过 |

## M0 · 准备与基础搭建（1~2个月）

### Sprint 0-1（第1~2周）：环境与资源准备
- [ ] 安装 UE5.3+，验证 Nanite / Lumen 可用
- [ ] 下载 Card Games Templates，评估复用点
- [ ] 收集 Marketplace 中式免费/低价资源清单（古建、水墨纹理、符箓元素）
- [ ] 整理参考美术风格板（新中式水墨3D风）
- **交付物**：资源清单 `docs/art/CONCEPTS/ASSET_LIST.md`

### Sprint 0-2（第3~4周）：工程框架搭建
- [ ] 建立 UE5 蓝图工程目录结构（Content/Cards、Content/Scenes、Content/FX）
- [ ] 创建核心 Data Table 骨架（卡牌属性、羁绊表、符箓表）
- [ ] 基础 UI 框架：主菜单、对战界面占位
- [ ] 完成 3 张概念卡牌低模（盘古、女娲、嫦娥）
- **交付物**：可启动的空白工程 + `docs/engineering/ARCHITECTURE.md` 初版

### Sprint 0-3（第5~8周）：基础卡牌原型
- [ ] 单张 3D 卡牌可在场景内拖拽
- [ ] 卡牌正面/背面纹理规范确立（2K/4K PBR）
- [ ] 3 个场景空白占位搭建（昆仑墟、古戏台、书斋）
- **交付物**：原型视频截图 + 场景占位包

## M1 · 核心玩法开发（2~3个月）

### Sprint 1-1（第1~2周）：卡牌系统
- [ ] 卡牌管理器（创建/分发/回收）
- [ ] 手牌区 3D 悬浮排列逻辑
- [ ] 卡牌物理交互（靠近推动效果，Chaos 物理）
- **交付物**：卡牌系统蓝图文档

### Sprint 1-2（第3~4周）：回合制战斗核心
- [ ] 回合管理器（Turn Manager）：玩家↔AI 切换、30秒计时
- [ ] 基础伤害/防御计算（灵将/符箓/文脉三类克制）
- [ ] 血量/能量条 UI 接入
- **交付物**：能完成一回合攻防的可玩 Demo

### Sprint 1-3（第5~6周）：AI 与特色机制
- [ ] 简单 AI（行为树 + 克制优先策略）
- [ ] 文脉羁绊系统（条件判断 + 属性加成 + 专属特效触发）
- [ ] 符箓共鸣机制（五行组合逻辑）
- **交付物**：能完整对战一局的 PvE Demo

### Sprint 1-4（第7~10周）：对战闭环与基础特效
- [ ] 胜负判定与结算界面
- [ ] 基础技能特效（水墨粒子、祥云，Niagara 实现）
- [ ] 15~20 张核心卡牌数据填表完毕
- **交付物**：M1 里程碑 Demo（完整一局 PvE 可玩）

## M2 · 美术与剧情完善（2~3个月）

### Sprint 2-1（第1~2周）：场景精化
- [ ] 昆仑墟：悬浮山石、祥云、古松细节贴图完成
- [ ] 古戏台：红灯笼、雕花栏杆纹理到位
- [ ] 书斋：笔墨纸砚陈设完成
- **交付物**：3 个场景截图对比（草稿 vs 精化）

### Sprint 2-2（第3~4周）：卡牌视觉升级
- [ ] 核心 10 张卡牌完成 4K 纹理与 PBR 材质
- [ ] 卡牌召唤出场动画（每张独特，Niagara 水墨特效）
- [ ] 卡牌背面统一中式纹样（回纹/云纹）
- **交付物**：卡牌视觉规范文档更新

### Sprint 2-3（第5~6周）：UI 完善
- [ ] 水墨风主菜单、战斗 UI 精化
- [ ] 卡牌详情界面（3D 旋转展示 + 文化小故事文本）
- [ ] 养成界面（升阶按钮 + 文脉碎片显示）
- **交付物**：UI 截图集

### Sprint 2-4（第7~10周）：故事模式内容
- [ ] 3 章故事剧情对话脚本（文脉守护者 vs 浊灵）
- [ ] 剧情界面 UMG + 角色简单 3D 动作
- [ ] 文化小故事文本绑定至卡牌详情（每张卡牌含1条）

- **交付物**：故事模式可完整通关

## M3 · 测试与优化（1~2个月）

### Sprint 3-1（第1~2周）：性能优化
- [ ] Nanite / Lumen 参数调优，目标 60fps（PC 中等配置）
- [ ] 纹理压缩、LOD、Occlusion Culling 配置完毕
- [ ] World Partition 动态加载验证
- **交付物**：性能报告 `docs/tech_art/PERF_BUDGET.md` 更新

### Sprint 3-2（第3~4周）：平衡性测试
- [ ] 15~20 张卡牌数值复盘（阶差 ≤5%）
- [ ] 羁绊/符箓组合过强情况修正
- [ ] AI 难度分级测试（初级/中级）
- **交付物**：平衡性测试报告

### Sprint 3-3（第5~8周）：全面测试与发布准备
- [ ] 全流程通关测试（故事模式 + 休闲对战）
- [ ] Bug 修复迭代
- [ ] 操作手感调整（拖拽流畅度、技能触发反馈）
- [ ] 首发版本打包与基本发行材料（截图、简介）
- **交付物**：MVP 发布候选版本
