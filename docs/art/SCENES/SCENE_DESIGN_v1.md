# 《文脉·山海卡》核心场景设计 — SCENES

**版本：** v1.0  
**作者：** Art Director  
**适配：** UE5 Nanite + Lumen + World Partition，模块化组件复用策略

---

## 场景设计总原则

- 每个场景对应一个明确的文化主题和情绪基调
- 所有场景元素设计为可复用组件，避免重复建模成本
- 场景底层结构：中景主体 + 远景虚化 + 前景框景（类国画三段式构图）
- 光照：Lumen 全局光照 + 定向主光 + 辅助 Sky Light

## 场景一：昆仑墟（上古神话战场）

### Moodboard 描述

**情绪基调：** 空旷 · 苍茫 · 神秘 · 清冷  
**时段设定：** 晨雾未散的黎明，或无时间感的神话永恒时刻  
**色调主色：** 石青（`#1A5276`）为天空底色，宣纸白雾气，墨黑山石轮廓

**意象来源：** 《山海经》描述的昆仑山——"其高万仞，其上有土地，万物不死"；宋代米家山水的积墨法；传统版画中的仙境构图

**构图逻辑（国画三段式）：**
- 前景：悬浮松树枝桠（框景，近黑）
- 中景：主战场区域，悬浮山台（卡牌对战平面）
- 远景：层叠悬浮山石，没入云雾，虚化处理

**核心视觉特征：**
1. 悬浮山石：不接触地面，在云雾中漂浮，下方有水墨晕染阴影
2. 古松：松枝向画面外延伸，枝干苍劲，参考黄山松造型
3. 祥云：并非卡通祥云，而是大团积墨云，有体积感
4. 整体大量留白（虚空）——空气和虚空是场景主角之一
5. 偶有仙鹤剪影飞过远景（动态点景）

**禁止元素：** 城市建筑轮廓、西方神殿柱、漂浮水晶、过于整齐的人造结构


## 场景二：古戏台（非遗对战擂台）

### Moodboard 描述

**情绪基调：** 热烈 · 喜庆 · 民俗 · 市井烟火  
**时段设定：** 夜晚灯火，或黄昏暖光  
**色调主色：** 朱红（`#C0392B`）为建筑主色，金黄灯笼光，深蓝夜空衬底

**意象来源：** 皮影戏台实物照片、山西王家大院戏台、老北京天桥表演场景、传统庙会年画氛围

**构图逻辑：**
- 前景：红柱框景，悬挂灯笼
- 中景：戏台主舞台面（卡牌对战平面），幕布为背景
- 远景：围观人群剪影（可选，低多边形点景），夜色院落

**核心视觉特征：**
1. 戏台建筑：歇山顶屋顶，斗拱飞檐，朱红立柱，彩绘匾额
2. 灯笼：大量红灯笼悬挂，暖黄发光，主要光源
3. 幕布背景：深红丝绒幕布，边缘金线绣花纹
4. 地面：青砖铺地，有岁月磨损感
5. 氛围光：温暖跳动的灯笼光，制造节庆感而非冷清感

**禁止元素：** 现代 LED 灯光、过于写实的人群、任何现代风格装饰

## 场景三：书斋（剧情叙事空间）

### Moodboard 描述

**情绪基调：** 宁静 · 书卷气 · 沉思 · 文人雅致  
**时段设定：** 午后阳光或黄昏暮色  
**色调主色：** 宣纸白（`#F5F0E8`）为主调，赭石木色，浓墨书卷，竹帘绿意

**意象来源：** 宋代《西园雅集图》中的文人空间、明代文震亨《长物志》描述的书斋陈设、日式和中式混合的静谧空间质感（仅取静谧气质，不取日式设计元素）

**构图逻辑：**
- 前景：竹帘/书案前缘（框景）
- 中景：主书案，主角站立位置，对话发生区
- 远景：书架/窗外竹影

**核心视觉特征：**
1. 书案：厚重榆木或紫檀书案，上置笔墨纸砚（文房四宝）
2. 书架：整齐的线装古籍，卷轴悬挂
3. 窗：格子窗，窗外竹影摇曳，漫射光透入
4. 地面：素色方砖，简洁
5. 整体克制，不堆砌器物——文人审美的"少即是多"

**禁止元素：** 现代书架设计、玻璃材质、过于精致豪华的宫廷装饰（书斋是私人空间，非公共殿堂）
