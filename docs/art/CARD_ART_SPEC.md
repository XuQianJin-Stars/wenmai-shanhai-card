## 一、卡牌物理规格

### 3D 模型规格

| 参数 | 规格 |
|------|------|
| 卡牌尺寸（世界空间） | 6.3 cm × 8.8 cm × 0.4 cm（接近真实卡牌比例 2.5:3.5 英寸） |
| 边角倒角 | R = 0.3 cm 圆角 |
| 多边形数量 | 约 200–400 面（薄型几何，依赖贴图表现细节） |
| 物理碰撞体 | 使用简化 Box Collision，不用 Complex Collision |
| 枢轴点位置 | 卡牌中心底边（便于翻转、出牌动画） |

### 整体布局层级（从下到上）

```
Layer 0: 卡牌基础几何（3D Mesh）
Layer 1: 宣纸底色材质（PBR Material）
Layer 2: 背景水墨层（Decal / Masked Material）
Layer 3: 角色/图案主体（Decal / Render Target）
Layer 4: 纹样边框层（独立 Mesh Panel，可动画）
Layer 5: 文字信息层（UMG Widget Component）
Layer 6: 高光/发光边缘层（Post Process / Emissive）
```

│  │                       │  │

### 2.2 角色插画区规格

**角色呈现方式：**
- 使用 UE5 Scene Capture 将独立角色渲染至 Render Target，贴回卡牌正面
- 角色姿态：标准站姿或半身构图（膝部以上），面向 3/4 侧
- 角色占插画区高度：60–75%（保留天空/背景留白）
- 角色边缘处理：使用水墨边缘溶解效果（Masked Material，边缘 Noise 纹理）

**水墨背景规格：**
- 背景基底：宣纸白 `#F5F0E8`，加水渍晕染效果（Decal 叠加）
- 背景元素：1–2 个场景标志物（如昆仑松、月轮、古建轮廓）
- 背景密度：近实远虚，主体后方浓墨，边缘淡化至宣纸底色
- 留白比例：背景区域 30% 以上保持宣纸底色裸露

**光照规格（UE5 Lumen）：**
- 主光源：斜侧光（45°），模拟古典工笔画打光
- 补光：顶部软柔光，石青色调（`#2E86C1`，强度 0.3）
- 环境光：采用 HDRI 宣纸纸面环境，Lumen 场景亮度 0.8–1.2

### 2.3 边框纹样规格

| 等级 | 边框样式 | 材质 |
|------|----------|------|
| 凡品（普通） | 回纹（单层，墨色） | PBR 漆黑材质，无发光 |
| 珍品（稀有） | 云纹（双层，赭石+金线） | 金箔材质，轻微 Emissive |
| 极品（史诗） | 莲纹+回纹复合（三层，金+朱砂） | 金箔 + 朱砂发光，动态光晕 |
| 文脉级（传说） | 万字纹+龙纹（四层，全金，动态） | 全金箔动态材质，粒子光效 |

> **critic LOW-001 补充说明（v1.1）：三类卡牌边框色使用分工**
>
> 上表为按**稀有度等级**划分的边框样式，另有一套按**卡牌类型**划分的边框主色规范（来自 STYLE_GUIDE v1.2 §七），两套规范叠加使用：
>
> | 卡牌类型 | 边框主色 | 颜色含义 | 暗部/内框细节色 |
> |---------|----------|---------|----------------|
> | 灵将卡 | 对应五行属性色（金/木/水/火/土） | 见 STYLE_GUIDE §2.1 五行标准色 | 水墨黑 `#1A1A1A` 内框 |
> | 符箓卡 | 朱砂红 `#C03A2A` + 藤黄 `#F4D03F` | 朱砂=符箓能量，金=神圣感 | 深朱红 `#7B241C` 内框 |
> | 文脉卡 | 土属性色 `#8C6040`（主色）+ 墨黑 `#1A1A1A`（内框） | 土色=大地/文化积淀感 | 矿物色赭石 `#7B3F00`（暗部纹样刻线、浮雕细节） |
>
> **区分要点：**
> - `#8C6040`（土属性标准色）= 文脉卡边框**主面色**，饱和度较高，用于边框宽面
> - `#7B3F00`（矿物色赭石）= 文脉卡**暗部/刻线细节**，更深更暗，用于浮雕凹槽和纹样内部阴影
> - 两色共存、不冲突，前者明，后者暗，构成文脉卡边框的立体层次感

**边框几何规格：**
- 外框宽度：卡牌短边的 6%
- 边框凸起高度：0.05 cm（微浮雕感）
- 四角装饰：云纹角花，独立 Mesh，可单独动画

### 3.2 背面视觉规格

- **背景色：** 宣纸白 `#F5F0E8`，叠加水墨晕染（深度居中，边缘留白）
- **中央纹样：** 太极图变体（去除现代化感，参考汉代铜镜纹样）
  - 尺寸：占背面面积直径 50%
  - 颜色：墨黑主体 + 朱砂细线勾边
  - 材质：轻微 Emissive（发光强度 0.1，朱砂金色）
- **外边框：** 万字纹（单层，金线 `#D4AF37`）
- **游戏标题：** "文脉·山海卡" 楷体，淡墨 `#8C8C8C`，字号 0.2 cm

### 3.3 背面统一性要求

- 所有卡牌背面完全一致（不区分等级）
- 背面禁止包含任何角色或功能信息（保证游戏公平性）

## 四、贴图规格（PBR 工作流）

### 4.1 贴图分级

| 卡牌等级 | 分辨率 | 用途 |
|----------|--------|------|
| 文脉级/极品卡 | 4096 × 4096（4K） | 核心英雄卡牌（盘古/女娲/嫦娥等） |
| 珍品卡 | 2048 × 2048（2K） | 稀有卡牌 |
| 凡品卡 | 1024 × 1024（1K） | 普通卡牌，Mip Map 自动缩减 |

### 4.2 贴图通道规格

| 通道 | 规格 | 说明 |
|------|------|------|
| Base Color | RGB，sRGB 色彩空间 | 漫反射色，包含水墨纹理细节 |
| Metallic | 灰度，Linear | 金属部分（边框金线/金属道具）0.7–1.0；其余 0.0 |
| Roughness | 灰度，Linear | 宣纸/墨迹：0.85–0.95；金属：0.2–0.4；丝绸：0.3–0.5 |
| Normal | RGB，Linear（TangentSpace） | 纸张纤维纹理 + 浮雕纹样法线 |
| Emissive | RGB，HDR | 仅高等级卡牌使用；朱砂/金箔区域 0.5–2.0 倍强度 |
| AO | 灰度，Linear | 纹样凹槽环境遮蔽 |

### 4.3 UE5 材质配置

```
Material Instance 参数：
- InkDensity          (0.0–1.0)  水墨浓度控制
- PaperAging          (0.0–1.0)  宣纸做旧程度
- GoldEmissiveScale   (0.0–3.0)  金箔发光强度
- CardGrade           (0–3)      0=凡品, 1=珍品, 2=极品, 3=文脉级
- BorderAnimSpeed     (0.0–2.0)  边框动态纹样动画速度
```

### 4.4 Substance Painter 工作流标准

1. **基础层：** 宣纸底纹（纤维纹理噪点）
2. **水墨层：** 手绘笔触叠加（Overlay/Multiply 模式）
3. **色彩层：** 矿物色填充（低饱和度，粗颗粒质感）
4. **金属层：** 金线/银线描边（Metallic 通道单独控制）
5. **磨损层：** 边缘磨损、轻微做旧（老卡牌质感，选用）
6. **输出：** Unreal Engine 4/5 预设导出

## 五、卡牌状态视觉规格

| 状态 | 视觉表现 |
|------|----------|
| 默认 / 手牌中 | 正常材质，无特效 |
| 悬停 / 选中 | 轻微上浮 0.3 cm，边框 Emissive 增强 0.3 |
| 出牌激活 | 边框金光扫描动画，纹样旋转 |
| 攻击命中 | 卡牌轻微震动，墨迹溅射粒子 |
| 升阶 | 全身金光 + 水墨纹样粒子散开，模型细节级别切换 |
| 禁用 / 消耗 | 变为灰度（Desaturate），透明度降至 60% |
| 翻转（出牌/查看） | Rotation Y 轴 180°，过渡帧 0.4s，加水墨拖影 |

## 六、UMG Widget 卡牌详情界面规格

当玩家点击卡牌查看详情时，展示完整 3D 卡牌旋转视图：

- **展示方式：** Scene Capture 渲染至 UMG Image，背景透明
- **交互：** 鼠标/触摸拖动旋转，双击复位
- **信息布局：** 左侧 3D 旋转视图，右侧文字信息（名称/属性/技能说明/文化小故事）
- **背景：** 半透明宣纸白蒙层（透明度 80%），不遮挡游戏场景
