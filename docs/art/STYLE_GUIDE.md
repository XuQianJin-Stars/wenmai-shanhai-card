## 一、核心美学定位

> **层级：MVP 必须层**

**关键词：** 笔墨意境、金石气韵、骨法用笔、计白当黑

本作追求的不是"贴了水墨皮的3D游戏"，而是让水墨语言成为造型和光影的本体。
参考意象：宋代院体山水的构图张力 + 汉代青铜器的线条力量 + 敦煌壁画的色彩饱和度控制。

**全局渲染基调（与 RENDER_PLAN.md 对齐）：**
- 全局降饱和：`Saturation ≈ 0.55`（UE5 Post Process Color Grading）
- 高光：冷白（偏石青）
- 阴影：蓝黑（`#1A1A1A` 偏蓝调）
- Bloom：仅触发高 Emissive 材质，避免整体发光感过强

### 2.4 禁用色（避免廉价感的色彩红线）

> **技术规范（已修正）：** 禁用"荧光色"定义为 **HSV 色彩空间中 S（饱和度）> 85% 且 V（明度）> 80% 的颜色**。

具体禁用示例（可在任何色彩选择器中验证）：

| 描述 | 参考色值（禁止） |
|------|-----------------|
| 纯卡通蓝 | `#0000FF`（HSV: 240°, 100%, 100%）|
| 霓虹绿 | `#00FF00`（HSV: 120°, 100%, 100%）|
| 荧光粉 | `#FF00FF`（HSV: 300°, 100%, 100%）|
| 日系魔法紫金渐变 | `#9B59B6` 到 `#F4D03F` 大面积渐变 |

- 禁止使用网游紫金渐变配色
- 人物皮肤禁止使用日系白瓷皮（`#FFE4C4` 类纯白肤色）；应参考汉画像砖的土赭肤色倾向（参考赭石 `#7B3F00` 系列调和）

## 三、描边与轮廓语言

### 3.1 MVP 必须层：基础描边规格

> **层级：MVP 必须层**

| 层级 | 粗细（屏幕空间） | 用途 |
|------|------------------|------|
| 主体轮廓 | 2.5–3.5 px（随距离缩放） | 角色/卡牌主轮廓 |
| 结构线 | 1.5–2.0 px | 衣褶、体块分面 |
| 细节线 | 0.5–1.0 px | 纹样内部、纹理细节 |
| 远景线 | 0.3–0.5 px（或消隐） | 背景山石、远树 |

**描边颜色规范：**
- 背光处：`#1A1A1A`（水墨黑）
- 迎光处：过渡至 `#5A5A5A`（中间调）

**MVP 实现方式：** UE5 Post-Process 材质 Outline（Edge Detection 节点），单层描边。

### 3.2 理想优化层：笔触抖动系统

> **层级：M3+ 迭代目标（MVP 阶段可跳过）**

- 边缘笔触抖动（Jitter Offset 0.5–1.5 px）：模拟毛笔笔触不均匀感
- 描边节点处顿笔感（方笔/圆笔交替）
- 角色眼睛描边必须粗于身体其他部位

**MVP 近似替代：** 统一描边厚度 + 角色主轮廓描边颜色略深于结构线即可。

### 3.3 轮廓语言规则（MVP 必须）

- **禁止等粗平滑的纯白描边**（联想：日系手游网红风格）
- 描边颜色必须基于水墨黑系，禁止使用彩色描边

## 四、水墨粒子规范

### 4.1 MVP 必须层：基础粒子语言

> **层级：粒子视觉方向为 MVP 必须层；具体贴图实现分层见下**

| 类型 | 视觉特征 | 对应技能/场景 |
|------|----------|---------------|
| 散墨粒子 | 墨滴扩散，边缘毛糙，从浓到淡 | 普通攻击碰撞、召唤出场 |
| 飞白粒子 | 细长笔触状，半透明白色 | 移动残影、风属性特效 |
| 泼墨粒子 | 大面积墨面扩散 | 大招、场景切换 |
| 符箓粒子 | 朱红发光，笔画轨迹感 | 符箓卡发动、增益/克制 |
| 祥云粒子 | 金黄线卷云，漩涡状 | 神将召唤、羁绊激活 |
| 月光粒子 | 螺钿银，散点状光斑 | 嫦娥专属、阴属性 |
| 水墨晕染 | 在背景上扩散的水渍感 | 场景入场、场景转换 |

**五行属性粒子颜色（与五行标准色对齐）：**
- 金系粒子：`#C8A04A` + `#F4D03F` 发光
- 木系粒子：`#4A8C5C` + `#27AE60` 轮廓
- 水系粒子：`#2A4A7A` + `#2E86C1` 发光
- 火系粒子：`#C03A2A` + `#D35400` 飞散
- 土系粒子：`#8C6040` + `#7B3F00` 碎片

### 4.2 理想优化层：手绘贴图集

> **层级：M3+ 迭代目标（MVP 阶段使用程序化替代）**

- 手绘墨迹贴图集（8–16 帧 Flipbook）
- 符箓笔画贴图集（楷书笔画纹理）
- 卷云形态贴图变体

**MVP 近似替代：** 使用程序化 Perlin Noise 形变的 Sprite Particle，颜色与方向遵循上述规范即可，贴图可使用引擎内置噪点。

### 4.3 Niagara 实现基础参数（MVP 参考）

- 粒子寿命：散墨 0.3–0.8s；祥云 1.5–3.0s；泼墨 0.6–1.2s
- 颜色模式：Lerp 从 `#1A1A1A`（满生命）到 `#5A5A5A`（淡出），alpha 曲线为先快后慢
- 符箓粒子：主色 `#C03A2A`（火属性/朱砂）+ 内发光 `#F4D03F`

## 五、留白原则

> **层级：MVP 必须层**

**核心美学：** 计白当黑，留白本身是造型语言。

### 空间留白

- 卡牌背景：主体人物占画面 50–60%，其余空间为水墨晕染背景（非填满构图）
- 背景处理：采用"近实远虚"——主体清晰，背景用大笔墨面处理，不做精细纹理
- 场景镜头：战斗摄像机构图必须保留天空/空间留白区域，不允许四角全满

### 色彩留白

- 任意画面中，宣纸白（`#F5F0E8`）的视觉占比不得低于 20%
- 矿物色（石青/石绿/朱砂）不得同时满版使用，至少一色降至 30% 以下透明度

### 文字/UI 留白

- 卡牌名称文字周围留白 ≥ 字高的 1.5 倍
- 信息密度：单张卡牌正面最多 3 行文字信息（名称/类别/关键词）

## 六、DO / DON'T 对比表

> **层级：MVP 必须层**

### 造型

| DO ✅ | DON'T ❌ |
|-------|---------|
| 脸型参考汉代俑、宋代塑像：圆润但不夸张，眼距自然 | 网红脸：超大眼睛、锥子下巴、高鼻梁 |
| 身材比例 6–7 头身，接近人体真实比例 | 日系卡通 8–9 头身夸张比例 |
| 衣纹参考汉服出土实物和敦煌壁画线描稿 | 现代汉服写真感的"飘带乱飞"过度风格化 |
| 武器/道具参考考古出土实物造型 | 西方奇幻武器（如巨剑/机械感装备） |
| 盘古：粗犷、苍劲，石肌肤质感，斧形参考良渚玉钺 | 盘古做成肌肉战士造型（西方神话投影） |

### 色彩

| DO ✅ | DON'T ❌ |
|-------|---------|
| 矿物色+水墨灰主色调，朱砂红/金箔金作点缀 | 全身色彩鲜艳饱和的日系配色 |
| 皮肤色参考赭石系列，有健康的温暖感 | 日系白瓷皮 |
| 光效使用金黄/朱红/石青等传统色 | 蓝紫色系魔法光效（西方奇幻投影） |
| 五行属性色使用标准色板 | 自行发明五行配色（保持团队一致性） |
| 卡牌背景使用单色系水墨晕染（墨色或矿物色单色渐淡） | 卡牌背景使用"冷色→金色"大面积双色渐变（如石青渐变至藤黄、深蓝渐变至金箔金）——与文物/水墨单色底原则相悖，易产生廉价感 |

### 特效

| DO ✅ | DON'T ❌ |
|-------|---------|
| 水墨扩散、笔墨轨迹、符箓朱光 | 激光线条、霓虹轮廓、赛博风发光 |
| 祥云、仙鹤、松鹤意象的粒子 | 西方魔法阵、五芒星、水晶碎片 |
| 大招使用泼墨感的黑色墨面扩散 | 爆炸光球、蘑菇云类视觉 |

### 场景

| DO ✅ | DON'T ❌ |
|-------|---------|
| 斗拱、回廊、石栏杆参考宋代建筑规制 | 清宫剧风格的过度金碧辉煌 |
| 庭院植物：松、竹、梅、芭蕉 | 热带植物、西方玫瑰、现代园林 |
| 昆仑墟：悬浮山石+清冷石青色调 | 异域火山/西方神殿风格 |

## 七、三类卡牌视觉语言速查表

> **层级：MVP 必须层**（响应 critic ART-NEW-001）

三类卡牌在视觉语言上必须有直观差异，玩家无需读文字说明即可感知类型。

| 维度 | 灵将卡（Spirit Cards） | 符箓卡（Talisman Cards） | 文脉卡（Culture Cards） |
|------|----------------------|------------------------|----------------------|
| **卡面主体** | 人物立绘为绝对主体（占画面 60-70%）；6–7 头身比例 | 符箓图案/笔画轨迹为主体，无人物或人物极小 | 非遗技艺场景、文物器物、典籍图像为主体；无战斗感 |
| **主视觉意象** | 英雄姿态，有动势感；衣袂飞扬但克制 | 抽象朱砂笔画在空中书写；几何构图 | 静物/场景构图；器物特写；文人雅集场景 |
| **边框色** | 五行属性色（金/木/水/火/土标准色）+ 水墨黑内框 | 朱砂红（`#C03A2A`）+ 藤黄（`#F4D03F`）金边 | 赭石（`#8C6040`）或墨色（`#3D3D3D`）+ 宣纸白内框 |
| **边框纹样** | 回纹或云纹，较规整，体现武将气势 | 八卦/阴阳意象，有旋转构图感 | 书卷/卷轴边框，仿古册页装帧感 |
| **卡背特征** | 属性色为底色，角色剪影水印 | 朱红底色，符箓水印 | 宣纸底色，古籍线条水印（如《山海经》插图风格） |
| **整体色调** | 全局降饱和基调下，以属性色为主调点缀 | 以朱红为绝对主色，金色作点光；高对比度 | 接近水墨原色（黑/灰/赭石），矿物色用量最少 |
| **AI Prompt 关键词参考** | `ink wash portrait, Tang dynasty general, Chinese brush painting, [attribute] color accent` | `red cinnabar talisman, calligraphy strokes glowing, Chinese exorcism charm, abstract composition` | `Song dynasty still life, Chinese antique artifact, guqin/porcelain/bamboo scroll, ink wash, no characters` |

### 三类卡牌核心视觉区分记忆口诀

- **灵将卡**：看到人 → 战将/神祇立绘，有人有气势
- **符箓卡**：看到红 → 朱砂发光，笔画书写感，无人物主体
- **文脉卡**：看到器/景 → 文物/场景/典籍，静谧文雅，无战斗感

## 八、MVP 三场景情绪板描述

> **层级：MVP 必须层**

### 7.1 昆仑墟

**情绪关键词：** 清冷、空寂、神圣、高远

- **主色调：** 石青（`#2A4A7A` + `#2E86C1`）+ 宣纸白（`#F5F0E8`）
- **光影偏好：** 顶光 + 侧光，强对比，无暖色填充
- **空间感：** 悬浮山石、薄云飘绕，视线向上延伸，远景消散在石青雾气中
- **禁止：** 暖黄光线、红色系装饰、热闹感
- **氛围参考：** 宋代山水长卷《千里江山图》的青绿基调，但去除绿色，以石青冷调为主

### 7.2 古戏台

**情绪关键词：** 暖热、喧闹、民间、戏剧感

- **主色调：** 朱砂红（`#C0392B`）+ 藤黄（`#F4D03F`）+ 深木色（`#7B3F00`）
- **光影偏好：** 暖黄灯笼侧光，多光源，阴影丰富
- **空间感：** 戏台居中，幕布鲜红，灯笼密集，有纵深感，观众席方向留黑
- **禁止：** 冷光源、现代灯光感、西式剧院感
- **氛围参考：** 民间年画的饱和度控制 + 传统戏服色彩系统（但在全局降饱和滤镜下）

### 7.3 书斋

**情绪关键词：** 静谧、文雅、温润、沉思

- **主色调：** 赭石（`#8C6040`）+ 宣纸白（`#F5F0E8`）+ 淡墨（`#8C8C8C`）
- **光影偏好：** 烛光暖色（偏橘）从低处投射，高处冷暗，形成上冷下暖对比
- **空间感：** 书架背景、案几居中，香炉细烟缓升，窗外月光作为副光源
- **禁止：** 明亮日光感、鲜艳装饰、动态感强的特效
- **氛围参考：** 宋人小品画的室内构图 + 文人画的色彩克制

## 九、资源模块化组件复用清单

> **层级：MVP 必须层（核心组件）；部分为 M2+ 目标**

### 装饰性组件（MVP）
- **祥云纹样笔刷**（4 种变体：如意云/三叠云/卷云/积云）
- **古松模型**（直干/斜干/悬崖松 3 种）
