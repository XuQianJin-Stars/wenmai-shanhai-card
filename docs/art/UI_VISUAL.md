## 一、UI 设计哲学

**核心原则：** UI 是场景的延伸，而非覆盖场景的遮罩。

- 半透明宣纸质感——UI 不阻断 3D 世界的可见性
- 水墨线条而非几何方块——边框用笔触感线条，非像素边框
- 信息密度克制——每个界面只展示当前必要信息
- 动效参考毛笔书写——渐显如墨渗入宣纸，非现代 Ease-In/Out 弹窗

## 二、视觉语言基础

### 2.1 底板材质

| 类型 | 样式 | 透明度 | 用途 |
|------|------|--------|------|
| 宣纸底板 | 宣纸纤维纹理，轻微做旧 | 75–85% | 主要信息面板、卡牌详情 |
| 墨色底板 | 深墨黑，无纹理 | 80–90% | 确认弹窗、重要提示 |
| 透明叠加层 | 无底色，仅线框和文字 | 100%（文字） | HUD 血量/能量显示 |
| 古卷底板 | 卷轴展开样式，边缘做旧泛黄 | 90% | 剧情对话框、文化小故事 |

### 2.2 边框语言

**禁止：** 像素边框、圆角矩形、现代 UI 卡片式外框

**使用：**
- 朱砂细线（`#C0392B`，1–2px）作为分隔线
- 墨色笔触状边框（不规则边缘，有笔压感）
- 回纹/云纹装饰角标（仅用于重要面板四角）
- 不规则边缘的"撕边"效果——宣纸被墨浸润的自然边缘

### 2.3 色彩规则

> **A-LOW-001 说明（v1.1 补充）：** 朱砂红 `#C0392B` / `#C03A2A` 作为火行卡牌属性色，不可直接复用为 UI 功能状态色（危险/警告），否则玩家会将"危险状态"误读为"火属性"。以下表格明确区分「五行标识色」和「UI 功能色」。

**UI 功能色（与五行属性色分离）：**

| 用途 | 颜色 | HEX | 备注 |
|------|------|-----|------|
| 主文字 | 水墨黑 | `#1A1A1A` | — |
| 次要文字 | 淡墨 | `#8C8C8C` | — |
| 强调/激活 | UI 朱红 | `#C0392B` | 仅用于 UI 强调，与火属性色视觉相近但语义不同 |
| 危险状态/低血量警告 | 警告橙红 | `#E74C3C` | 偏橙，区别于火属性标准色 `#C03A2A` |
| 禁用状态 | 淡墨灰 | `#C8C8C8` | — |
| 成功/增益 | 石绿 | `#27AE60` | — |
| 警告/损耗（轻度） | 赭石橙 | `#A04000` | — |
| 高亮边框 | 金箔金 | `#D4AF37` | — |

**五行标识色（卡牌属性/技能颜色，来自 STYLE_GUIDE Section 2.1）：**

| 属性 | HEX | 使用场景 |
|------|-----|---------|
| 金 | `#C8A04A` | 金属性卡牌边框/图标/粒子 |
| 木 | `#4A8C5C` | 木属性卡牌边框/图标/粒子 |
| 水 | `#2A4A7A` | 水属性卡牌边框/图标/粒子 |
| 火 | `#C03A2A` | 火属性卡牌边框/图标/粒子（禁止用于 UI 危险状态） |
| 土 | `#8C6040` | 土属性卡牌边框/图标/粒子 |

### 2.4 字体系统

| 层级 | 字体 | 字重 | 字号（参考 1080p） |
|------|------|------|-------------------|
| 主标题 | 楷体 / 思源宋体 Heavy | Bold | 36–48px |
| 次标题 | 仿宋体 | Regular | 24–30px |
| 正文 | 思源宋体 | Light | 18–22px |
| 小字注释 | 思源宋体 | ExtraLight | 14–16px |
| 数值 | 等宽宋体数字 | Regular | 20–28px |

## 三、核心 UI 组件规格

### 3.1 手牌区（Battle Hand Area）

**位置：** 屏幕底部，水平居中  
**布局：** 3D 卡牌悬浮排列，扇形展开（最多 7 张）

```
视觉规格：
- 卡牌悬浮高度：底部边缘露出 30%（隐藏状态），鼠标移入展开至 60%
- 相邻卡牌间距：动态，随卡牌数量调整（始终在屏幕宽度 70% 内）
- 选中效果：上浮 1.5 倍高度 + 边框金色 Emissive 增强
- 底部遮挡：宣纸半透明渐变条（从屏幕底边向上渐隐），高度 15% 屏幕高
- 卡牌叠压：当卡牌数量 > 5，左右两侧卡牌适当叠压（叠压量 20%）
```

**UMG 节点结构建议（给 engineer）：**
```
WBP_HandArea
  ├─ Canvas_Background (半透明宣纸渐变)
  ├─ HorizontalBox_Cards
  │    └─ [动态生成] WBP_CardSlot × N
  │         ├─ SceneCapture_CardPreview
  │         ├─ Overlay_SelectionGlow
  │         └─ Text_CardName (悬停时显示)
  └─ Widget_HandCount (当前手牌/上限)
```

---

### 3.2 血量 / 能量条（Status Bars）

**风格：** 不使用矩形进度条，使用"水墨笔触消耗"样式

```
血量显示：
- 形式：垂直竹简样式，上方是满值，墨迹从上向下"褪去"表示损耗
- 满血：深墨黑填充，朱砂红边框
- 低血（<30%）：墨迹颜色变为赭石橙，轻微闪烁
- 位置：屏幕左右两侧（玩家右侧，对手左侧），竖排

能量/法力显示：
- 形式：横向"文脉碎片"计数（圆形石青色宝石状图标）
- 满能量：石青发光；消耗后图标变为灰色宣纸纹理
- 位置：血量条下方
```

**UMG 节点结构建议：**
```
WBP_StatusBar
  ├─ Image_BambooFrame (背景竹简纹理)
  ├─ ProgressBar_HP (自定义材质，水墨褪去效果)
  ├─ Text_HPValue
  ├─ HorizontalBox_Energy
  │    └─ [动态生成] Image_EnergyOrb × N
  └─ Overlay_LowHPWarning (可见性由蓝图控制)
```

### 3.3 技能释放区（Skill Panel）

**位置：** 屏幕右侧，垂直排列  
**风格：** 简洁图标，无复杂边框

```
图标规格：
- 尺寸：64×64px 基础（可缩放）
- 背景：圆形宣纸底板，边缘墨色晕染
- 图标本体：水墨线描风格（非全彩填充），参考道家符箓线条感
- 冷却效果：朱砂顺时针填充（而非常规灰色遮罩）
- 不可用：整体降饱和 + 透明度 50%
- 激活特效：图标发出石青光晕短暂闪烁（0.3s）
```

---

### 3.4 剧情对话框（Dialogue Box）

**风格：** 古卷展开样式

```
展开动画：
- 卷轴从中央向两侧展开（X 轴 Scale 0→1，时长 0.5s）
- 展开同时纸张纹理淡入（Alpha 0→1，时长 0.3s，延迟 0.1s）
- 文字出现：逐字显示，速度 40字/秒，每字如墨渗纸（alpha 0→1 per char）

布局：
- 上部：角色立绘（水墨边缘处理的半身像）左侧或右侧
- 中部：宣纸底板文字区，楷体正文
- 下部：朱砂细线分隔 + 选项按钮（如有）

按钮样式：
- 水墨笔触状下划线，非矩形按钮
- 悬停：朱砂红色下划线加粗
- 选中：轻微墨迹扩散效果（Niagara 2D 微粒子）
```

**UMG 节点结构建议：**
```
WBP_DialogueBox
  ├─ Image_ScrollBackground (卷轴纹理)
  ├─ WidgetAnimation_ScrollOpen
  ├─ Image_CharacterPortrait
  ├─ RichText_DialogueContent (支持逐字动画)
  ├─ Text_CharacterName (楷体，朱砂色)
  └─ VerticalBox_Choices (可选项，默认隐藏)
       └─ [动态生成] WBP_DialogueChoice × N
```

### 3.5 文脉区（WenMai Zone）

> **层级：MVP 必须层**  
> **拍板来源：** producer 方案3（2026-04-30）— 底部手牌区上方独立横条  
> **关联规则：** CORE_LOOP_v2 §六：文脉区上限6张，文脉卡进文脉区不进弃牌堆，持续驻留至被摧毁

**位置：** 手牌区（WBP_HandArea）上方，战场区下方，水平横条全宽铺展

```
横条尺寸规格（1080p 基准）：
- 高度：单张文脉卡高度 × 1.2（含上下留白；卡牌高度约 120px，横条高约 144px）
- 宽度：与中央战场区等宽（屏幕宽度 × 0.85，居中对齐）
- 上间距（距战场区底部）：16px
- 下间距（距手牌区顶部）：12px
- 背景：极浅宣纸底色（#F5F0E8，透明度 40%），边缘用淡墨 #8C8C8C 笔触状细线（0.5px）框定
- 区域标签：左侧固定显示「文脉区」楷体小字（14px，淡墨 #8C8C8C），无边框
```

**卡牌在文脉区的视觉状态：**

```
悬浮高度：3cm（世界空间，相较于手牌区平铺；区别于灵将卡 8cm 高悬浮）
卡牌角度：正面平铺朝向玩家，轻微 X 轴前倾 5°（便于扫视）
间距规则：6张满场时均匀分布横条宽度，间距最小 8px；< 6张时靠左对齐
激活状态（羁绊已激活）：卡牌边框产生对应五行属性色光晕（Emissive 0.8），脉冲周期 2s
失活状态（羁绊未激活）：边框无光晕，赭石色 #8C6040 淡线框
被摧毁动画：卡牌在 0.4s 内以「墨迹溶解」方式消失（Dissolve 材质从外向内），随后坠入弃牌堆
```

**入场平移动画规范（给 tech_artist + engineer）：**

```
触发时机：玩家打出文脉卡后（符合 CORE_LOOP_v2 §二 C 分支）

起始坐标：手牌区对应卡槽的世界坐标（WBP_HandArea > WBP_CardSlot.Position）
目标坐标：文脉区对应槽位坐标（WBP_WenMaiZone > WBP_WenMaiSlot[N].Position）

动画曲线：EaseOut（出手快，入位缓——模拟轻放动作）
动画时长：0.45s
位移方向：向上平移（Y 轴负方向，距离约为手牌区到文脉区的垂直间距）
水平对齐：同步向目标槽位 X 坐标滑动（斜线路径，非直角折线）

伴随特效：
- 平移过程：卡牌底部拖出淡墨尾迹（#8C8C8C，透明度 30%，宽 2px，持续 0.3s 后淡出）
- 落位瞬间：文脉区卡牌边框从无光晕渐亮至赭石底光（0.2s），发出古琴单音（由 audio 对接）
- 如当前已激活羁绊：落位 0.1s 后立即触发属性色光晕脉冲
```

**UMG 节点结构建议（给 engineer）：**

```
WBP_WenMaiZone
  ├─ Image_ZoneBackground     (宣纸底色横条，40% 透明度)
  ├─ Text_ZoneLabel           (「文脉区」楷体标签，左固定)
  ├─ HorizontalBox_WenMaiSlots
  │    └─ [动态生成] WBP_WenMaiSlot × 6（最大容量）
  │         ├─ SceneCapture_CardPreview
  │         ├─ Overlay_ActiveGlow    (羁绊激活时属性色光晕，默认 Hidden)
  │         └─ Image_InactiveFrame   (赭石淡线框，默认 Visible)
  └─ Text_SlotCount           (「N/6」当前容量，右固定，14px 淡墨)
```

**视觉层次逻辑（三层明确分区）：**

```
[中央战场区]  ← 灵将卡，8cm 高悬浮，战斗单位
      ↕ 16px 间隔
[文脉区横条]  ← 文脉卡，3cm 低悬浮，持续效果
      ↕ 12px 间隔
[手牌区]      ← 全部类型卡牌，等待打出
```

禁止：文脉区使用与战场区相同的悬浮高度（会混淆文脉卡与灵将卡）  
禁止：文脉区背景使用朱红色（朱红为符箓卡专属感知色）

### 3.6 卡牌详情界面（Card Detail View）

**触发：** 点击/长按任意卡牌

```
布局：
- 背景：全屏半透明宣纸蒙层（透明度 85%）
- 左侧 60%：3D 卡牌旋转视图（Scene Capture）
- 右侧 40%：竖排信息区

信息区内容（上→下）：
1. 卡牌名称（楷体，36px，墨黑）
2. 类别 + 文脉属性（仿宋，24px，朱砂）
3. 朱砂细线分隔
4. 属性数值（攻/防/能量消耗，等宽数字字体）
5. 技能说明（仿宋，18px，墨黑）
6. 朱砂细线分隔
7. 文化小故事（思源宋体 Light，16px，淡墨）
8. 来源典籍引文（14px，斜体，更淡墨）

关闭方式：点击蒙层任意处 / ESC 键
关闭动画：宣纸蒙层向下滑出 + 卡牌缩回原位
```

## 四、动效规范

### 基础动效原则

- **参考意象：** 毛笔在宣纸上的书写——先慢后快（出锋），收尾减速（回锋）
- **禁止：** 弹性弹窗（Bounce）、过度旋转、赛博感滑动

### 常用动效参数

| 动效类型 | 曲线类型 | 时长 | 备注 |
|----------|----------|------|------|
| 界面入场 | EaseInOut | 0.3s | 透明度 0→1 |
| 界面出场 | EaseIn | 0.2s | 向下滑出 |
| 卡牌悬停 | Linear | 0.15s | 位移上浮 |
| 卡牌出牌 | EaseOut | 0.4s | 飞向战场 |
| 文字逐显 | Linear | per-char | 40字/秒 |
| 按钮悬停 | EaseInOut | 0.2s | 颜色过渡 |
| 卷轴展开 | EaseOut | 0.5s | X Scale |
| 窗口关闭 | EaseIn | 0.2s | Alpha + 位移 |
