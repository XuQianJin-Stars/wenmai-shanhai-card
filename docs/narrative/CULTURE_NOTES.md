## 神话创世组（盘古 + 女娲）

**羁绊名称**：开天绪脉

**弹出文本**：

盘古开天时，他的身体化为了天地万物：呼出的气变成风云，左眼成了太阳，右眼成了月亮，四肢化作山岳，血脉化作江河。这个故事最早出现在三国时吴国人徐整写的《三五历纪》里——连盘古本人，也是那个时代才"被创造出来"的神。

女娲的故事更古老。《山海经》《楚辞》里她已经在了，抟土造人，炼石补天，她是最早的"修复者"。

两个人合在一起：一个打开混沌，一个修复破损。这不只是神话，也是中国人对"创造与修缮"这两件事最古老的理解。

**来源**：徐整《三五历纪》（三国·吴），《山海经·大荒西经》，《楚辞·天问》

## 八仙组（吕洞宾 + 铁拐李 + 何仙姑 + 蓝采和 + 张果老 + 汉钟离 + 韩湘子 + 曹国舅）

**羁绊名称**：八仙同渡

**弹出文本**：

八仙不是同一个时代的人，最早的传说里他们各自行事，是元代才逐渐被"凑成一组"的——明代吴元泰的小说《八仙出处东游记》，是最早把八人完整凑齐的文本。

有意思的是，八仙几乎每个人都来自底层：跛脚乞丐、穷书生、村姑。没有帝王，没有将军。道教的仙，从来不是贵族的专利。

"八仙过海，各显神通"——这句话本身就是一种文脉：它告诉你，每个人用自己手头的东西就能渡过去，用扇子、用花篮、用葫芦。不必等人施舍。

**来源**：吴元泰《东游记》（明），《列仙全传》（明·王世贞）

## 非遗组（皮影 + 剪纸 + 刺绣）

**羁绊名称**：手艺三生

**弹出文本**：

皮影、剪纸、刺绣，三种都是"用手在平面上讲故事"的艺术。

皮影戏最迟在汉代已有，从驴皮或牛皮上镂刻人形，对着灯光投影演戏——一个人躲在白布后面，操纵几根细杆，能演整场大戏。剪纸流传数千年，春节窗花是它最家常的形态，但最复杂的剪纸可以镂刻出整幅山水。刺绣在《诗经》时代便已是贵重衣物的标志，苏绣、湘绣、蜀绣各有门道。

这三件手艺的共同点：都被联合国教科文组织列入非物质文化遗产名录，都在逐渐失去年轻传承人。文脉这件事，从不只发生在典籍里。

**来源**：《汉书·外戚传》（皮影早期记载），联合国教科文组织非遗名录（2009年、2009年、2009年分别入选）

## 五行组（五行符全套激活）

**羁绊名称**：五行归元

**弹出文本**：

五行不是迷信，是一套古代的分类系统——把世界上所有的事物按照金、木、水、火、土五种特质归类，再用"相生相克"的关系描述它们如何互动。

这套系统有一段漫长的发展史：《尚书·洪范》最早记载"五材"（水火木金土五种实体物质），是概念的萌芽；战国《吕氏春秋》《管子》将其发展为相生相克的动态关系；西汉《淮南子》和董仲舒《春秋繁露》将其系统化并融入宇宙论；《黄帝内经》则将五行引入医学，成为中医核心框架。

今天中医还在用五行，不是因为古人不懂科学，而是因为这套语言在描述"关系"和"动态平衡"时，确实有它的逻辑在。

**来源**：《尚书·洪范》（五材早期记载），《吕氏春秋》（战国·相生相克体系），《淮南子》（西汉·系统化），《黄帝内经·素问》（医学应用）

## 古韵诗仙组（李白 + 杜甫）

**羁绊名称**：诗脉双流

**弹出文本**：

李白和杜甫见过面，而且是真实历史中有文献记录的会面——公元744年，两人在洛阳相遇，杜甫后来写了十五首诗念李白，李白只写了两首怀念杜甫的诗。这个"数量差"，让后世文学研究者争论了一千年。

李白是浪漫主义，杜甫是现实主义；李白写仙，杜甫写民；李白的文脉连着道教昆仑，杜甫的文脉连着人间土地。两种诗风相遇，不是对立，是互补。

游戏里激活这个羁绊，是在说：再飘逸的精神，也需要脚踏实地的心；再沉重的现实，也需要一点仰望星空的勇气。

**来源**：《新唐书·杜甫传》，杜甫《春日忆李白》《冬日有怀李白》等

## 门神组（神荼 + 郁垒）

**羁绊名称**：守门双将

**弹出文本**：

神荼、郁垒是中国最古老的门神，早于秦叔宝、尉迟恭至少一千年。《山海经》里就有他们的雏形，传说他们居住在东海度朔山上的大桃树下，负责检查出入鬼魂，用苇绳捆绑作恶的鬼，扔去喂老虎。

后来人们把桃木刻成他们的形象，挂在门上，这就是"桃符"的起源。王安石的诗"爆竹声中一岁除，春风送暖入屠苏，千门万户曈曈日，总把新桃换旧符"——"旧符"说的，就是这件事。

贴门神这个习惯，在中国延续了至少两千年，形象从桃木偶换成了纸画，但守护家门的心意从未变过。

**来源**：《山海经·海外东经》，《荆楚岁时记》（南朝），王安石《元日》（北宋）

## 嫦娥·月兔组（嫦娥 + 玉兔）

**羁绊名称**：广寒相伴

**弹出文本**：

嫦娥奔月的故事，最早的版本里她并不是主动飞升的——《淮南子》记载，嫦娥偷了后羿的不死药，飞升月宫。东汉张衡的《灵宪》记载她化为蟾蜍："姮娥遂托身于月，是为蟾蜍"，汉代画像石和敦煌壁画中也有蟾蜍形象。直到后来故事慢慢被"美化"，蟾蜍消失，出现了美丽的仙女形象。

玉兔出现得更晚，捣药的动作来自长生不老药的联想，在唐代诗歌里已是常见意象。李白写"小时不识月，呼作白玉盘"，杜甫写"美人娟娟隔秋水"——月亮是中国诗歌里被写得最多的意象之一。

嫦娥和玉兔同框，是孤独的配对：一个因为出走而永远留在了那里，一个陪伴的动物也不能说话。

**来源**：《淮南子·览冥训》，《搜神记》（晋·干宝），唐代月宫壁画（敦煌莫高窟）

## 龙王组（东海龙王 + 南海龙王）

**羁绊名称**：四海同源

**弹出文本**：

中国的龙和西方的龙完全不同——西方龙喷火、是恶的象征，中国龙掌水、是吉祥与权威的象征。但"龙王"这个词其实是外来的："王"（Raja）的概念来自佛教经典传入中国后的改造，把原本的"龙（nāga）"与中国本土的龙神合并，才有了今天的龙王形象。

四海龙王的体系最迟在唐代成型，《西游记》里孙悟空借如意金箍棒的东海龙王敖广，是这一形象最家喻户晓的文本来源。

"龙的传人"这个说法其实历史并不长，二十世纪才大量流行。但龙作为图腾，中国考古发现的最早证据距今约六千年（河南濮阳蚌塑龙，约公元前4000年）；辽宁红山文化C形玉龙距今约五千五百年，是目前造型最完整的早期龙形象之一。

**来源**：《山海经》（龙雏形），《西游记》（明·吴承恩），红山文化玉龙（辽宁省博物馆藏）
