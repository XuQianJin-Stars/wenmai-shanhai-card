## 一、对局参数基线

| 参数 | 数值 |
|------|------|
| 制式 | 1v1 回合制 |
| 目标局长 | 5–8 分钟 |
| 主将初始 HP | **20**（producer 拍板） |
| 初始手牌 | 先手 4 张 / **后手 5 张**（后手额外 1 张补偿） |
| 初始灵力 | 先手第 1 回合 **2 点**（+1 灵力补偿先手不抽牌）；后手第 1 回合 1 点 |
| 灵力规则 | 每回合重置并 +1，上限 10 |
| 牌库上限 | 20 张 |
| 每回合抽牌 | 1 张（先手首回合不抽牌） |
| 每回合出牌上限 | 无硬限制（受灵力约束） |
| 单回合最大攻击次数 | **2 次**（任意灵将，防止哪吒/封神组滥用） |
| 胜负判定 | 对手主将 HP ≤ 0 **或** 牌库耗尽后无法抽牌 |

**先手/后手平衡说明：**
- 先手：首回合不抽牌（手牌4张），但首回合灵力=2，可更早打出中费卡
- 后手：起始5张手牌，首回合灵力=1
- 设计意图：先手用灵力优势，后手用手牌优势，两者在不同维度互补

## 三、克制关系说明（修订版 v0.2）

### 3.1 卡牌类型克制（三角关系）

```
灵将卡  →（克制）→  符箓卡
符箓卡  →（克制）→  文脉卡
文脉卡  →（克制）→  灵将卡

克制效果：ATK × 1.1（调低为 +10%，原 +20% 过强）
```

### 3.2 五行克制矩阵（战斗修正）

| 攻方五行 | 被克制方 | 克制加成 |
|----------|----------|----------|
| 金 | 木 | ATK × **1.3** |
| 木 | 土 | ATK × **1.3** |
| 土 | 水 | ATK × **1.3** |
| 水 | 火 | ATK × **1.3** |
| 火 | 金 | ATK × **1.3** |
| 同属性 | — | ATK × 1.0（无加成） |

### 3.3 克制上限说明（v0.2 最终版）

```
★ v0.3 修订（D-BLK-002）：废除卡牌类型克制（×1.1）
  仅保留五行克制，单一克制上限 = ×1.3

  计算示例：
  哪吒（火，ATK7）攻击金属性灵将（火克金）：
  五行克制 1.3 × ATK7 = 9.1 → 取整 = 9

  最高伤害校验（盘古极品 ATK10 × 1.3 = 13）：
  对 DEF8 目标穿透 = 13 - 8 = 5 → 安全
```

**设计意图：** 单一克制体系更清晰，新手友好；×1.3 倍率兼顾策略深度与数值安全。

## 四、符箓共鸣触发时序（修订版）

```
出牌阶段打出符箓卡
  → 加入「已打符箓五行记录」（全局累积，不重置）
  → 检测本局已打出的五行标签种类
      → 金木水火土各≥1张（五种全打出）→ 触发【五行结界】（本局限 1 次）
          ├─ 即时：我方所有灵将 DEF +2
          ├─ 持续 2 回合：我方主将受到的每次伤害 -1
          └─ 纯防御型，无进攻性附加
```

**触发难度说明（S-MED-003 修订后）：** 需在本局打出全部5种五行符箓，触发概率约60-70%（需多属性构建），属于有代价的高光奖励；每局限触发1次。
详见 RESONANCE.md §三 完整触发逻辑。

## 五、文脉羁绊触发时序

```
出牌阶段打出灵将卡或文脉卡
  → 检测场上+文脉区所有卡牌的「羁绊标签」
      → 某组羁绊标签全部在场 → 触发该羁绊效果
          ├─ 属性增益立即生效
          ├─ 解锁专属场景特效（美术 Tag 输出）
          └─ 解锁对应文化小故事（叙事 Tag 输出）
  → 任一羁绊成员离场 → 该羁绊失效，属性增益撤销
```

## 六、文脉区规则（新增明文，修复 CRIT-D-004）

```
★ 文脉卡游戏区域规则（必须明确）：

1. 文脉卡打出后进入「文脉区」，不进入「弃牌堆」
2. 文脉卡在文脉区时：
   - 持续提供增益效果
   - 参与羁绊判定
   - 可被特定符箓效果直接摧毁（摧毁后才进入弃牌堆）
3. 「回收类技能」（如 WM-004 皮影剪纸谱）只能检索弃牌堆，
   不能检索文脉区的文脉卡
4. 文脉区上限：6 张（超出时玩家自选 1 张移入弃牌堆）

```

## 七、控制状态限制（新增，修复 R-004）

```
连续控制上限规则：
  同一目标灵将不可处于「连续控制状态超过 2 回合」
  - 眩晕+封印不叠加计算，均视为"控制状态"
  - 若第 3 回合依然有控制效果，该效果自动失效
  - 计算示例：FL-003 水行符（眩晕 1 回合）+ 玄武共鸣（+1 回合）= 2 回合，合法
             FL-003（2回合/珍品版）+ FL-005 封印（2回合）同时作用 = 超出上限，封印提前失效

```

## 八、防御效果叠加规则（新增，修复 R-001/004）

```
防御叠加规则：
  同类防御效果（减伤/免疫/护盾）不叠加，取当前最高值：
  - 女娲五彩石（减伤 1-2 点）vs 镇煞大阵（每回合免疫 1 点固定伤害）
    → 取最高值，不额外叠加
  - 主将单次受击最低伤害 = 2（硬下限，任何减伤不能使单次伤害低于 2）

```

## 十一、Onboarding Flow — 首次游玩体验路径（新增，回应 R-D01）

> 设计目标：零基础玩家在第一局开始后 5 分钟内，无需阅读说明文字，仅凭视觉和音效直觉就能感知三类卡牌的核心差异。

### 三类卡牌"感知层设计"矩阵

| 维度 | 灵将卡 | 符箓卡 | 文脉卡 |
|------|--------|--------|--------|
| **卡框颜色** | 暖色（金/铜边框） | 冷白/银边框 | 竹青/墨绿边框 |
| **出牌动画** | 召唤冲击波，角色从卡面"站出来"，悬浮高度 8cm | 边框闪烁后消失（打出即消失，无残留） | 平移至文脉区，光纹亮起，低悬浮（3cm）持续 |
| **出牌音效** | 战鼓短击+皮革质感（"实体进场"） | 毛笔落纸声+瞬间消散音（"立即结算"） | 古琴拨弦单音+3-5秒长衰减（"持续驻留"） |
| **玩家直觉联想** | 像棋子/战士，"站在场上打架" | 像法术/道具，"打出就没了" | 像装备/场地，"放着一直生效" |

**三个自解释信号（无需文字说明）：**
1. **边框颜色色相差 >90°**，色盲友好（避免红绿对比），新手可直觉区分三类
2. **出牌后是否"留下来"**：灵将/文脉卡留在场上，符箓卡打出后消失——这是最核心的直觉差异
3. **音效的"拖尾长度"**：古琴长音=持续效果，战鼓短击=实体单位，笔纸消散=即时消耗

### 三步引导流程（强制新手教程）

```
Step 1（回合 1）：强制展示一张已选定的"低费灵将"
  → 悬停提示：金色边框图标 + "灵将会留在场上，可以攻击"
  → 玩家打出后：观察角色"站立"在场上区域

Step 2（回合 2）：强制发一张低费符箓
  → 悬停提示：银色边框图标 + "符箓立即生效，打出后消失"
  → 玩家打出后：观察符箓卡消散动画

Step 3（回合 3）：强制发一张文脉卡
  → 悬停提示：墨绿边框图标 + "文脉卡放入文脉区，持续生效"
  → 玩家打出后：观察卡牌平移至文脉区并持续发光

```

**后续设计注意：** 克制关系（+10%/+20%）在前5回合不做教程重点，让玩家先熟悉三区域布局。克制关系通过"攻击时高亮目标卡框颜色"做隐性提示——有克制加成时，目标卡框闪烁红色；无克制时，无特效。
