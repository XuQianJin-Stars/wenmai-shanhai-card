## 数据字段说明

| 字段 | 说明 |
|------|------|
| ID | 卡牌唯一标识，格式：LJ（灵将）/ FL（符箓）/ WM（文脉）+ 三位序号 |
| 中文名 | 卡牌显示名称 |
| 阵营 | 上古神话 / 八仙传说 / 非遗文脉 |
| 类型 | 灵将卡 / 符箓卡 / 文脉卡 |
| 费用 | 出牌所需灵力（1–8） |
| ATK | 攻击力（凡品基础值） |
| DEF | 防御力（凡品基础值） |
| HP | 生命值（凡品基础值，仅灵将卡有） |
| 五行 | 金 / 木 / 水 / 火 / 土 |
| 基础技能 | 凡品自带技能 |
| 珍品技能 | 升阶至珍品后解锁 |
| 羁绊标签 | 触发文脉羁绊的组合标识 |
| 文化原型出处 | 必须标注文献/典籍 |
| 美术需求标签 | 提供给 art_director（无详细描述，仅风格关键词） |
| Counter | 被什么克制或压制 |

## 附录：典籍出处核实报告（narrative v0.2）

> 撰写：narrative | 日期：2026-04-30
> 针对 designer 请求核实的 7 条文化原型出处，逐一说明修订理由。

### LJ-001 盘古 — 出处正确，补充注记

- **原始引用**：《三五历纪》（三国·徐整）
- **核实结论**：正确。《三五历纪》确为最早系统记载盘古神话的文献。
- **补充**：原书已佚，现存内容辑录于《太平御览》《艺文类聚》及清·马骕《绎史》卷一。已在卡牌出处字段加注。
- **关于"盘古是否应引《山海经》"**：**否。《山海经》无盘古记载。** 盘古神话的最早文字来源是三国时期的《三五历纪》，晚于《山海经》数百年，两者不可混用。

### LJ-002 女娲 — 出处正确，建议区分事迹

- **原始引用**：《淮南子·览冥训》
- **核实结论**：正确。女娲补天的权威来源是《淮南子·览冥训》（西汉·刘安）。
- **补充**：女娲**造人**事迹的最早来源是《风俗通义》（东汉·应劭），非《淮南子》。若图鉴涉及造人，须另引此书，已在出处字段补充区分。
- **关于"女娲是否应优先引《山海经》"**：**《山海经·大荒西经》仅简短提及女娲，不是补天/造人故事的核心文本。** 按事迹引用更准确：补天引《淮南子》，造人引《风俗通义》。

### LJ-003 哪吒 — 回目范围有误，已修订

- **原始引用**：《封神演义》第十二回
- **核实结论**：不够精确。哪吒闹海的核心情节跨越第十二至十四回，不限于第十二回。已修订为"第十二至十四回"。
- **补充**：哪吒的更早文化原型是唐代佛教护法神"那吒俱钵罗"（梵语：Nalakuvara），见《北方毗沙门天王随军护法仪轨》，《封神演义》属后世汉化演绎版本。已在出处字段加注。

### LJ-004 钟馗 — 出处有两处错误，已修订

- **原始引用**：《补笔谈》（北宋·沈括）
- **核实结论**：**有误，须修订。**
  1. 钟馗故事的最早权威文献是《太平广记》卷二百九十引《唐逸史》（唐·卢肇），记唐明皇梦中钟馗斩鬼的完整故事。
  2. 沈括在**《梦溪笔谈》**（非《补笔谈》）中有相关考证，《补笔谈》是其续补之作，两书不同，原引用书名有误。
  3. 沈括的考证是次级来源，非原典，不宜作为第一出处。
- **已修订为**：《太平广记》卷二百九十引《唐逸史》（唐·卢肇）为主要出处，沈括《梦溪笔谈》为考证参考。

### LJ-005 吕洞宾 — 书名混淆，已修订

- **原始引用**：《历代神仙通鉴》卷十四
- **核实结论**：**书名有误。**《历代神仙通鉴》（清·徐道，约康熙年间）与《历世真仙体道通鉴》（元·赵道一，1294年）是两部不同著作，书名相近极易混淆。
- **吕洞宾最权威的早期来源**是《历世真仙体道通鉴》（元·赵道一），该书为现存最早系统记载吕洞宾事迹的道教仙传文献。
- **已修订为**：《历世真仙体道通鉴》（元·赵道一）+ 《东游记》（明·吴元泰）。

### LJ-006 铁拐李 — 回目指向不准，已修订

- **原始引用**：《东游记》第二回
- **核实结论**：需修订。《东游记》第二回的主要内容是钟离权度化吕洞宾，铁拐李的济世葫芦故事贯穿多回，不限第二回。
- **已修订为**：《历世真仙体道通鉴》（元·赵道一）为早期来源；《东游记》（明·吴元泰）为通俗来源，不锁定具体回目。

### WM-006 昆仑仙境图 — 篇目有小误，已更正

- **原始引用**：《山海经·西山经》
- **核实结论**：轻微有误。"百神之所在"的昆仑描述出自《山海经·**海内西经**》，非《西山经》（《西山经》仅描述昆仑山的地理特征，未有"帝之下都"等神话定性语句）。《穆天子传》引用正确。
- **已修订为**：《山海经·海内西经》 + 《穆天子传》。
