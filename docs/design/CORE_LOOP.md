### 1.1 先手后手平衡机制说明（PLAY-001 修订）

**问题回顾：** 先手首回合不抽牌惩罚不足，先手建立早期场面优势后难以逆转。

**修订方案（采纳方案 A）：**

后手玩家首回合开始时，自动获得 1 张「文脉汇聚」虚拟牌（不占手牌上限，不来自牌库）：
- 费用：0
- 效果：使用后立即获得 +1 灵力（本回合有效）
- 首回合结束时若未使用，自动消耗（不保留至下回合）

**方案对比评估：**

| 方案 | 描述 | 优势 | 劣势 |
|------|------|------|------|
| **方案 A（采纳）** | 后手获得「文脉汇聚」虚拟牌 | 与游戏文化主题契合；灵力补偿直接有效；炉石"幸运币"已验证可行性 | 需要工程实现虚拟牌逻辑 |
| 方案 B | 先手首回合灵力为 0 | 实现简单 | 完全剥夺先手首回合出牌能力，破坏游戏节奏 |
| 方案 C | 后手初始手牌 5 张 | 手牌优势明显 | 手牌差距加剧中期优势，过矫 |

## 二、基础数值范围定义（PLAY-002 修订）

### 2.1 灵将卡数值区间

| 品质 | ATK 范围 | DEF 范围 | HP 范围 | 费用范围 |
|------|---------|---------|--------|---------|
| 凡品（基础） | 2–8 | 1–6 | 5–12 | 1–6 |
| 珍品 | 3–9 | 2–7 | 6–14 | 同凡品 |
| 极品 | 4–10 | 3–8 | 7–15 | 同凡品 |

**ATK 档位设计意图：**
- 低档（2–4）：辅助型灵将，偏重技能/DEF
- 中档（5–6）：均衡型，攻守兼备
- 高档（7–8）：攻击核心，DEF 低、HP 中等

### 2.2 克制叠加安全验证

```
最大单次伤害验算（凡品）：
  最高 ATK = 8（盘古）
  最大克制倍率 = 1.44×（五行克制 1.2× + 卡牌类型克制 1.2×）
  最大实际 ATK = 8 × 1.44 = 11.52 → 取整 = 12

  最高 DEF = 6（女娲）
  最低穿透伤害 = 1（设计保底）
  最大实际伤害（vs 最高 DEF）= 12 - 6 = 6

  最低 HP = 5（设计最低值），最大伤害 6 > 5 → 可 one-shot 极低 HP 目标
  常规最低 HP = 8（铁拐李），6 < 8 → 无法 one-shot 常规目标
```

**结论：** 1.44× 倍率在当前数值框架下，仅能 one-shot HP ≤ 6 的灵将（设计允许的极端情况）；常规灵将（HP ≥ 8）无法被单次 one-shot。数值安全。

### 2.3 符箓卡伤害区间

| 效果类型 | 数值范围 |
|---------|---------|
| 固定伤害（无视 DEF） | 1–4 点 |
| ATK 加成 | +1 至 +3 |
| DEF 加成 | +1 至 +3 |
| HP 回复 | 1–4 点 |
| 控制持续 | 1–2 回合 |

### 2.4 文脉卡增益区间

| 效果类型 | 数值范围 |
|---------|---------|
| ATK 持续加成 | +1 至 +3 |
| DEF 持续加成 | +1 至 +2 |
| 减伤（每次） | 1–2 点 |
| HP 回复（每回合） | 1–2 点 |

## 四、三类卡牌系统说明

### 4.1 克制关系

```
灵将卡  →（克制）→  符箓卡
符箓卡  →（克制）→  文脉卡
文脉卡  →（克制）→  灵将卡

克制效果：被克制类型的卡牌在战斗/技能结算中，额外受到 20% 伤害加深（四舍五入）
```

### 4.2 三类卡牌本质差异

| 卡牌类型 | 结算方式 | 场地区域 | 视觉颜色 | 音效特征 | 类比直觉 |
|---------|---------|---------|---------|---------|---------|
| **灵将卡** | 进入场地，持续存在 | 场上区（下方） | 金红暖色调 | 战鼓短击 + 皮革质感，短促有力 | "派一个人上场" |
| **符箓卡** | 立即结算，进入弃牌堆 | 无（即用即消） | 蓝白冷色调 | 毛笔落纸声 + 即时消散（无拖尾） | "施一个法术" |
| **文脉卡** | 进入文脉区，持续生效 | 文脉区（上方） | 绿色/水墨调 | 古琴拨弦 + 长衰减（3–5 秒拖尾） | "挂一道持续增益" |

## 六、符箓共鸣触发时序（v0.2 修订 — 响应 PLAY-003）

**PLAY-003 修订说明：** 原触发条件（累积凑齐金木水火土各 1 张）+ 原效果（全场 DEF+3 持续 2 回合 + 敌方额外伤害）存在必胜 combo 雏形，已做如下修订：

```
出牌阶段打出符箓卡
  → 加入「已打符箓记录」（全局累积，不重置）
  → 检测本回合已打符箓的五行标签集合
      → 本回合内已打出 ≥3 种不同五行的符箓卡
          → 触发【五行结界】（本局限 1 次）
              ├─ 我方主将获得「元气护盾」——抵消下一次受到的直击伤害（一次性）
              └─ 我方所有灵将 DEF +1，持续 1 回合
      → 累积打出同五行符箓 ≥2 张
          → 触发对应【单行共鸣】（详见 RESONANCE.md）
```

**修订要点：**
1. 五行结界触发条件从"累积凑齐全部5种"改为"单回合内凑3种"，门槛降低但需要单回合灵力投入
2. 效果从"全场 DEF+3（2回合）+ 进攻附加"削弱为"一次性护盾 + DEF+1（1回合）"
3. 本局限触发 1 次，杜绝重复利用

> 详细共鸣矩阵见：docs/design/RESONANCE.md

## 七、文脉羁绊触发时序

```
出牌阶段打出灵将卡或文脉卡
  → 检测场上+文脉区所有卡牌的「羁绊标签」
      → 某组羁绊标签满足激活门槛 → 触发该羁绊效果
          ├─ 属性增益立即生效
          ├─ 解锁专属场景特效（美术 Tag 输出）
          └─ 解锁对应文化小故事（叙事 Tag 输出）
  → 任一羁绊成员离场 → 该羁绊失效，属性增益撤销
```

> 详细羁绊组设计见：docs/design/BOND_SYSTEM.md

## 十、新手引导路径（Onboarding Flow）

**核心问题（来自 critic）：** 零基础新手 5 分钟内能否直觉理解三类卡牌的差异，无需阅读文字说明？

### 10.1 多感官分化设计

三类卡牌在**视觉、音效、区域**三个维度同时形成区别，新手通过直觉即可感知：

**视觉层（art_director 负责落实）：**

| 卡牌类型 | 卡框形状 | 颜色基调 | 背面图案 | 出牌区域 |
|---------|---------|---------|---------|---------|
| 灵将卡 | 盾形卡框，宽边厚重 | 金红暖色 | 战旗纹 | 场上区（屏幕下半部） |
| 符箓卡 | 圆角符纸形，轻薄感 | 蓝白冷色 | 符文圆阵 | 无专属区（打出即消失） |
| 文脉卡 | 横向卷轴形 | 绿色水墨 | 山水图 | 文脉区（屏幕上方横栏） |

**音效层（audio 已输出方案，见 SFX_LIST.md）：**

- 灵将卡：战鼓短击 + 皮革质感，短促有力 → 传达"实体进场/占据位置"
- 符箓卡：毛笔落纸声 + 即时消散（无拖尾）→ 传达"立即结算/一次性消耗"
- 文脉卡：古琴拨弦 + 长衰减（3–5 秒拖尾）→ 传达"持续驻留/效果保留"

三类音效在**音色族群、时值长度、衰减曲线**三个维度同时形成区别。

**区域层（工程/UI 落实）：**

```
┌────────────────────────────────────────────┐
│  [文脉区] 文脉卡横向排列（绿色卷轴，持续存在）  │
├────────────────────────────────────────────┤
│           [对手场上区] 灵将卡竖排              │
├────────────────────────────────────────────┤
│           [我方场上区] 灵将卡竖排              │
├────────────────────────────────────────────┤
│     [手牌区] 混合牌型，出牌时区域高亮提示       │
└────────────────────────────────────────────┘
```

当玩家拖动符箓卡时，场上无目标区域高亮（因为它立即结算），给玩家直觉暗示"这张牌不需要去某个区域"。

### 10.2 首次游玩体验流程（5 分钟目标）

**第 0–30 秒：视觉认知**
- 进入对战时，三类手牌呈现不同外观（形状/颜色不同）
- 悬停任意手牌，UI 右侧弹出 1 行提示：「灵将·上场守护」/「符箓·即用即效」/「文脉·常驻增益」
- 无需点击，悬停 2 秒自动收起

**第 30–120 秒：操作发现**
- 新手首局默认提供一副"引导牌组"，前 3 回合固定抽到 1 张灵将、1 张符箓、1 张文脉
- 打出灵将卡后，场上区出现明显光圈 + 战鼓音效，玩家感受到"它在这里了"
- 打出符箓卡后，光效爆发后消失，音效短促结束，玩家感受到"它用完了"
- 打出文脉卡后，文脉区出现卷轴展开动画，古琴持续回响，玩家感受到"它还在"

**第 120–300 秒：机制发现**
- 第 3 回合触发一次小羁绊（引导牌组保证），弹出文化小故事卡片（叙事内容）
- 玩家通过"羁绊触发 = 相关卡牌在场"直觉理解文脉区的价值

### 10.3 克制关系的延迟教学策略

**设计原则：** 克制关系（+20% 伤害）不在第一局教，而是通过数字反馈让玩家自己发现。

- 当克制触发时，伤害数字颜色变为**橙色**（非克制为白色），无文字说明
- 第二局结束后，出现"战斗总结"界面，显示"克制加成触发 X 次"，附带简短说明
- 玩家在战斗中先观察到橙色数字 → 战后看到说明 → 建立因果认知

### 10.4 新手简化模式评估

**critic 建议：** 是否考虑新手模式只使用灵将 + 符箓两类（暂时移除文脉卡）？

**评估结论：** **暂不采纳，但提供可选引导模式**

理由：
1. 文脉卡是本作最大的文化差异化特色（持续的"文化场域"概念），从教程起点就移除会损害核心体验
2. 三类卡牌的区分已通过多感官设计降低认知成本，可先验证实际反馈
3. **折中方案：** 新手引导牌组只放 1 张文脉卡（而非 3–4 张），让玩家先感受"一张文脉卡的价值"，再逐步扩展
