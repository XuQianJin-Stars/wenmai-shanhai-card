## 一、羁绊系统总则

### 1.1 设计理念

文脉羁绊（Bond System）是本作最核心的文化表达机制。通过将同一神话体系、历史传说或非遗主题的卡牌放入牌组，玩家可在场上集齐"文化圈"触发专属增益效果，同时解锁对应文化典故的叙事片段。

**三大设计原则：**
1. **文化真实性**：每组羁绊必须有明确的历史/神话文化依据
2. **策略深度**：触发羁绊需要 deck 构建代价，但收益明显高于同等费用的单卡
3. **叙事整合**：激活羁绊时触发场景特效 + 解锁对应文化小故事（narrative 负责文案）

### 1.2 通用激活机制

```
出牌阶段打出灵将卡或文脉卡
  → 检测「场上区」+ 「文脉区」中所有卡牌的羁绊标签
      → 某组羁绊所需标签全部满足 → 触发激活
          ├─ 立即生效：数值增益（一次性或持续，见各组说明）
          ├─ 美术触发：专属场景特效（art_director 输出）
          └─ 叙事触发：文化小故事解锁（narrative 输出）
  → 任意羁绊成员离场（阵亡/被弃） → 该羁绊失效，持续增益撤销
  → 一次性效果已触发则不再重复（即使成员重新满足条件）
```

### 1.3 激活判定区域

| 区域 | 是否计入羁绊判定 |
|------|----------------|
| 场上区（灵将卡） | ✅ 是 |
| 文脉区（文脉卡） | ✅ 是 |
| 手牌 | ❌ 否 |
| 弃牌堆 | ❌ 否 |
| 牌库 | ❌ 否 |

## 二、分层激活说明（解决 PLAY-004 问题）

部分羁绊组（尤其是八仙组）采用**分层触发**设计，解决"凑满全组概率极低"导致羁绊形同虚设的问题。

**分层公式：**

```
门槛1（2张）→ 触发基础效果（低增益，容易达成）
门槛2（4张）→ 触发增强效果（中增益，需要 deck 投入）
门槛3（6张+）→ 触发终极效果（高增益，强策略目标）
```

每个门槛只触发**增量效果**（不叠加），门槛之间的效果**不重复计算**。

**文化来源：** 中国上古神话创世体系——盘古开天、女娲补天造人
**典籍依据：**

- 女娲：《淮南子·览冥训》（汉·刘安）、《风俗通义》（东汉·应劭）
- 女娲五行属性 = 火（《淮南子·览冥训》五彩炼石补天，DECISION-001 producer 拍板）

#### 激活成员

| 卡牌 ID | 卡牌名称 | 类型 | 羁绊贡献 |
|---------|---------|------|---------|
| LJ-001 | 盘古·开天 | 灵将卡 | 必须 |
| LJ-002 | 女娲·补天 | 灵将卡 | 必须 |
| WM-001 | 盘古创世图 | 文脉卡 | 可选（激活后强化） |
| WM-002 | 女娲五彩石 | 文脉卡 | 可选（激活后强化） |

#### 激活条件与效果（S-MED-001 修订：改为一次性效果）

| 门槛 | 激活条件 | 效果类型 | 效果 |
|------|---------|---------|------|
| 基础激活 | 场上同时有 LJ-001 盘古 + LJ-002 女娲 | **一次性** | 两者 ATK 和 DEF 各 +2（永久，直至该卡离场）；我方主将立即回复 3 点 HP |
| 强化激活 | 基础激活 + 文脉区有 WM-001 或 WM-002 任意一张 | **一次性** | 额外：全场我方灵将 HP 上限 +2（立即生效，不恢复已损失 HP） |
| 完全激活 | 基础激活 + 文脉区同时有 WM-001 和 WM-002 | **一次性** | 额外：解锁「创世神力」——盘古和女娲技能费用各 -1 |

> **设计说明（S-MED-001）：** 创世组基础激活由原"主将每回合回复1HP持续增益"改为"立即回复3HP一次性"，避免持续增益在 20HP 主将框架下叠加过强（原版等效于全局免疫>3回合伤害）。一次性效果保持高光感，但无法通过保持羁绊状态持续累积。

#### 数值公式

```
创世组基础增益（一次性触发时数值）：
  盘古 ATK: 8 → 10（+2，永久附加在卡牌上）
  盘古 DEF: 4 → 6（+2，永久附加在卡牌上）
  女娲 ATK: 5 → 7（+2，永久附加在卡牌上）
  女娲 DEF: 6 → 8（+2，永久附加在卡牌上）
  主将 HP: 立即回复 3 点（不超过上限）

强化激活额外效果：
  全场灵将 HP 上限: +2（不叠加，已激活不重复触发）

完全激活额外效果：
  盘古技能费用: -1
  女娲技能费用: -1
```

#### 反制方式

- 集中消灭盘古或女娲任意一张，防止对方再次激活（一次性效果已触发则无法收回，但羁绊失效后无持续收益）
- 在对手完成创世组基础激活前，用高伤压倒盘古（激活前 ATK 8，被击杀后无法触发）
- 「焚天符」清除文脉区 WM-001/WM-002，阻止完全激活

#### 叙事解锁文本（触发时弹出）

> "天地初开，鸿蒙判分。盘古以身化山川，女娲以手补苍天——创世之力，一现于此。"

## 四、羁绊组跨组互动规则

| 规则 | 说明 |
|------|------|
| 同一张卡可属于多个羁绊 | 例：WM-001「盘古创世图」同时属于「创世组」计数 |
| 不同羁绊效果可同时生效 | 若玩家同时激活创世组+镇煞组，两者增益叠加计算 |
| 同类型增益（ATK加成）叠加上限 | 基础值 ×1.5，防止无限堆叠（绝对值上限见 CORE_LOOP §4.2） |
| 五行克制不干扰羁绊判定 | 五行克制只影响战斗伤害，不影响羁绊激活/失效判定 |
| 同类防御效果 | 取高值，不叠加（CORE_LOOP §4.3；镇煞完阵激活后显式执行此规则） |

### Bond + Resonance 双触发规则（S-CROSS-001 producer 拍板）

**决策时间：** 2026-04-30 | **决策依据：** 保留高光时刻，避免双系统互斥降低策略深度

```
同一回合 Bond 和 Resonance 双触发时：
  ATK 加成：取 Bond 或 Resonance 中较高的 ATK 加成值，不叠加
  DEF 加成：正常叠加，但单回合 DEF 加成上限 = +3
  其他效果（HP回复/技能解锁/抽牌等）：正常叠加，不受此规则限制
```

**示例：**
- 创世组触发 ATK+2 + 朱雀共鸣 ATK+2 → 同回合 ATK 加成取高值 = +2（不变为+4）
- 创世组触发无 DEF 加成 + 土行共鸣 DEF+2 → DEF 加成 = +2（正常）
- 创世组（无DEF）+ 土行共鸣（DEF+2）+ 镇煞组（DEF+1）→ DEF = min(2+1, 3) = +3（达到上限）

**设计意图：** 防止 15-20 张小卡池下 ATK 双叠加变成必胜组合，同时保留 DEF 的高光叠加感（单回合最多+3 DEF 已足够戏剧性）。

## 六、孤立卡单卡激活效果（producer 拍板 D03）

MVP 阶段封神组和非遗组各只有 1–2 张卡牌，无法触发羁绊。为避免玩家感到"抽到废牌"，为两组孤立卡设计**单卡自激活效果**（单张在场即自动激活，强度约为羁绊效果的 40%）。

| 卡牌 | 孤立卡效果 | 激活条件 | 是否与羁绊效果叠加 |
|------|----------|---------|-----------------|
| LJ-003 哪吒（封神组孤立） | **「逆天斗志」**：本回合攻击命中后获得 1 灵力（每回合最多 1 次） | 哪吒在场上，且当前封神组激活成员 < 2 张 | 羁绊激活后替换为羁绊效果，不叠加 |
| WM-004 皮影剪纸谱（非遗组孤立） | **「匠心活化」**：从弃牌堆回收的卡牌本次打出费用 -1 | 皮影剪纸谱在文脉区，且当前非遗组激活成员 < 2 张 | 羁绊激活后替换为羁绊效果，不叠加 |

**注：** 孤立卡效果在羁绊激活后自动失效并替换为羁绊增益，无需手动切换。
