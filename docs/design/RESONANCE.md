## 一、符箓共鸣系统总则

### 1.1 设计理念

符箓共鸣（Resonance System）将中国传统五行思想转化为卡牌游戏机制：当玩家累积使用特定五行属性的符箓卡时，天地元气在场上交汇，触发超越单张卡牌的宏观效果。

**核心设计目标：**
- 让玩家感受到"五行相生相克"不只是数值乘数，而是场上气势的转变
- 给符箓卡提供除"即时效果"外的额外战略价值
- 通过特殊共鸣触发稀有文化意象（龙凤、阴阳、天地等）

### 1.2 共鸣触发机制（v0.2）

```
出牌阶段打出符箓卡
  → 卡牌五行标签加入「已打符箓记录」（全局，不随回合重置）
  → 触发判定：
      检测「已打符箓记录」中五行标签分布
      → 满足任一共鸣条件 → 触发对应共鸣
      → 五行结界：本局唯一触发（集齐5种）
      → 单行共鸣：每种每局可多次触发（冷却 3 回合）
      → 特殊共鸣：阴阳交汇每局≤2次，天地玄黄每局1次
```

**关键规则：**
- 「已打符箓记录」跨回合累积，不重置
- 共鸣效果持续期间，该五行属性卡牌获得视觉特效标记
- Bond + Resonance 双触发规则见 BOND_SYSTEM.md §四

## 二、五行基础克制矩阵

### 2.1 相克关系（用于战斗伤害修正）

> **v0.2 修订（RV-H-001）：** 五行克制倍率从 ×1.2 改为 ×1.3，与 CORE_LOOP_v2 §3.1 同步。
> 旧版「类型克制 ×1.2」已废除，双克制不再存在，最大倍率上限 = ×1.3（单五行克制上限）。

```
五行相克（顺时针）：

        木
       ↗  ↘
     水     火
     ↑       ↓
     金←─土←─┘

克制方向：金克木 → 木克土 → 土克水 → 水克火 → 火克金

```

| 攻方五行 | 被克方 | 战斗效果 |
|---------|--------|---------|
| 金 | 木 | 攻击方 ATK × **1.3** |
| 木 | 土 | 攻击方 ATK × **1.3** |
| 土 | 水 | 攻击方 ATK × **1.3** |
| 水 | 火 | 攻击方 ATK × **1.3** |
| 火 | 金 | 攻击方 ATK × **1.3** |
| 同属性 | — | ATK × 1.0（无加成） |
| 其他无克制关系 | — | ATK × 1.0（无加成） |

**最大伤害校验：**

```
ATK 最高值 = 10（盘古 创世组触发后）
五行克制上限 = ×1.3
最高单次伤害 = 10 × 1.3 = 13 → 向下取整 = 13
最高 DEF = 8（女娲 创世组触发后）
实际穿透伤害 = 13 - 8 = 5
最高 HP = 14（盘古 基础12 + 强化激活+2）
  → 需至少 3 次 ×1.3 攻击才能击杀 → 数值安全
```

### 2.2 相生关系（用于共鸣增益方向参考）

```
五行相生（顺时针）：

        木
       ↙  ↖
     水     火
     ↑       ↓
     金←─土←─┘

生旺方向：木生火 → 火生土 → 土生金 → 金生水 → 水生木
```

> **女娲五行归属（DECISION-001）：**
> 女娲 = 火（《淮南子·览冥训》五彩炼石补天）
> 盘古 = 土（《三五历纪》"化为万物，土为中央"）
> 相生关系：盘古（土）生女娲（火）中的「火生土」——创世组文化逻辑自洽。

## 三、五行结界（producer 最终拍板版）

### 3.1 触发条件与效果

**触发条件（S-MED-003 修订后最终版）：**
- **本局累积打出全部 5 种五行属性的符箓卡各至少 1 张**（金木水火土各≥1）

> **变更说明：**
> - 原 v0.1 版：「本局累计打出五行各1张」 → 20张牌库中五行平均分布，约90%概率触发 = 实质无门槛
> - 中间版本：「同回合3种不同五行」 → 单回合需7-8灵力，触发时机太晚
> - **最终版（S-MED-003）：** 「本局累计5种五行全打出」 → 需要多种属性符箓入组，构建有代价，整局约60-70%触发概率，属合理高光奖励

**效果（产出纯防御型，producer 拍板）：**

```
五行结界激活效果：
  即时：我方所有灵将 DEF +2（本局不叠加，仅生效一次）
  持续：我方主将受到的每次伤害 -1（持续 2 回合）
  本局限触发 1 次
```

**触发逻辑（工程参考）：**

```
// 每次打出符箓卡后检测
five_elements_complete = (
  ResonanceLog_Metal >= 1 AND
  ResonanceLog_Wood >= 1 AND
  ResonanceLog_Water >= 1 AND
  ResonanceLog_Fire >= 1 AND
  ResonanceLog_Earth >= 1
)

IF five_elements_complete AND NOT resonance_flags["五行结界"]:
  ACTIVATE(五行结界)
  all_player_generals.DEF += 2  // 一次性，不可叠加
  player_hero.DamageReduction = 1  // 持续 2 回合
  resonance_flags["五行结界"] = true  // 本局不再重复触发
```

## 四、单行共鸣（五种）

各单行共鸣在**本局累积打出同五行符箓 ≥2 张时**触发，持续 2 回合，本局可多次触发（冷却 3 回合）。

### 金行共鸣 — 白虎肃杀

| 项目 | 内容 |
|------|------|
| 触发条件 | 本局累积打出金属性符箓 ≥2 张 |
| 效果 | 我方所有灵将对金属性/木属性目标攻击时，ATK 额外 +1；我方主将物理防御 +1 |
| 持续 | 2 回合 |
| 冷却 | 3 回合（**从效果结束的当前回合结束时起算**，即效果结束后第4回合方可再次触发） |
| 视觉 | 白虎纹路从场地边缘向中心蔓延，金属粒子环绕 |
| 文化意象 | 西方白虎，主肃杀，五行主金 |
| 反制 | 火克金：敌方打出火属性符箓可提前消除此共鸣 |

### 木行共鸣 — 青龙生旺

| 项目 | 内容 |
|------|------|
| 触发条件 | 本局累积打出木属性符箓 ≥2 张 |
| 效果 | 我方每回合开始时额外抽 1 张牌（持续期间）；我方木属性灵将 HP 上限 +2 |
| 持续 | 2 回合 |
| 冷却 | 3 回合（**从效果结束的当前回合结束时起算**，即效果结束后第4回合方可再次触发） |
| 视觉 | 青龙鳞纹从文脉区向场上延伸，嫩芽粒子飘散 |

### 水行共鸣 — 玄武困锁

### 火行共鸣 — 朱雀燎原

## 五、特殊共鸣（2 种）

### 特殊共鸣 A：阴阳交汇（Yin-Yang Convergence）

**文化来源：** 《易经》阴阳哲学，"一阴一阳之谓道"（《系辞传》）；水火既济（《周易·既济卦》）

| 项目 | 内容 |
|------|------|
| 触发条件 | 同一回合内，我方打出的符箓卡中同时包含「火」和「水」属性（火水相克，极性相反） |
| 触发名称 | 阴阳调和 |
| 效果 | 我方所有灵将本回合 ATK 和 DEF 同时 +2；若此时敌方有任意「五行结界」或「单行共鸣」处于激活状态，立即消除 1 个（随机）；我方主将回复 3 HP |
| 持续 | 1 回合（强力但短暂） |
| 本局限制 | 每局可触发 2 次 |
| ATK 叠加说明 | 若同回合 Bond 也触发 ATK 加成，按 BOND_SYSTEM §四「S-CROSS-001」规则取高值 |
| 视觉 | 黑白太极纹在场地中央旋转，阴阳鱼交汇爆发 |
| 音效 | 高频（朱雀音色）与低频（玄武音色）同时奏响后合并为和弦 |

**文化注释：** 火（阳极）与水（阴极）本为相克，《易经》以坎离交媾象征阴阳调和，此共鸣正是"水火既济"之象。

---

### 特殊共鸣 B：天地玄黄（Heaven-Earth Resonance）

**文化来源：** 《千字文》开篇"天地玄黄，宇宙洪荒"；《道德经》"道生一，一生二，二生三，三生万物"

| 项目 | 内容 |
|------|------|
| 触发条件 | 本局我方累积打出符箓卡总数 ≥10 张（包含所有五行属性） |
| 触发名称 | 天地归元 |
| 效果 | **终极效果（本局只能触发 1 次）：** 从弃牌堆随机取回 2 张符箓卡加入手牌；我方主将 HP 恢复至上限的 50%（若已超 50% 则+3）；我方所有文脉区卡牌本回合无法被任何效果消除 |
| 持续 | 恢复和手牌为即时；文脉保护持续 1 回合 |
| 本局限制 | 每局只能触发 1 次 |
| 视觉 | 全场特效：天空出现玄黄交替光柱，五行符文同时显现，10秒长动画（可跳过） |
| 音效 | 全部五行音色叠加，加入编钟长音，15 秒内收束 |

**设计意图：** 给"全符箓流"构建方式设置超强终局奖励。触发门槛（10 张符箓）意味着至少 50% 牌库都是符箓卡，高风险构建路线。

## 七、共鸣与羁绊的交互规则

| 交互场景 | 规则 |
|---------|------|
| 共鸣效果 + 羁绊增益 ATK | 同回合双触发：取较高 ATK 加成，不叠加（S-CROSS-001，详见 BOND_SYSTEM §四） |
| 共鸣效果 + 羁绊增益 DEF | 正常叠加，单回合上限 +3（S-CROSS-001） |
| 其他效果叠加 | HP回复/技能解锁/抽牌等均正常叠加，无互斥 |
| 阴阳交汇消除敌方共鸣 | 随机消除 1 个，包括五行结界；不影响羁绊 |
| 天地归元「文脉保护」 | 仅保护文脉区 1 回合，不永久解除符箓克制规则 |
| 单行共鸣被克制消除 | 视为提前失效，不消耗「触发次数」（可重新触发，但需重走冷却） |
